# gateway/

OmniMux 服务端网关。

> **源码尚未放入。** 发布时，本目录的源码将与 omnimux.ai 线上运行的网关版本一致。

## 内容

- 多模态模型接口转发（文本、图像、视频、音频）
- 异步生成任务的提交、轮询与结算
- 账户、令牌与积分管理

## 上游与许可

基于 [QuantumNous/new-api](https://github.com/QuantumNous/new-api) 二次开发，new-api 基于 [One API](https://github.com/songquanpeng/one-api)。

本目录采用 AGPL-3.0，并须保留 new-api 的署名与链接，详见 [NOTICE](../NOTICE)。网关部分的商业授权由 new-api 作者提供，见 [COMMERCIAL.md](../COMMERCIAL.md)。
