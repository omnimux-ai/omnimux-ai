# Slideshow Creation Publication Governance

## Decision

`slideshow/slideshow-creation` remains a public business skill because its primary value is sequential content planning, copy, reference breakdown, slideshow generation guidance, and diagnosis.

It is not treated as a code-execution skill.

## Runtime Boundary

Runtime-readable files are the `SKILL.md` entrypoint plus explicitly referenced support files under `references/`.

Rendering, template matching, batch search, image generation, and persistence are visible tool capabilities. They are not hidden defaults.

## Public Use Conditions

- Use for slideshow outlines, copy packs, reference breakdown, template-guided creation, generation, variants, and diagnosis.
- Do not persist a template unless the user explicitly requests a generated/persisted slideshow artifact.
- Do not turn copy, planning, reference breakdown, or diagnosis into a generation task.
- Do not claim template IDs, image URLs, or gallery matches without visible tool evidence.
