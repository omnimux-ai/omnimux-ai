# visualHint 组装指南

> 位置：`references/platforms/xiaohongshu/prompt-assembly.md`
> 用途：指导 Agent 为每页生成高质量的 `visualHint`（配图提示），确保图文视觉一致性
> 何时读取：Copy Generation 阶段（Step 5），与文案同步生成 `visualHint`

---

## 核心原则

1. **风格锁定**：确定 `style` 后，全组图的 `visualHint` 必须使用同一套风格关键词
2. **布局显式**：每页 `visualHint` 必须体现对应的 `layout` 类型（不能模糊写"图文排版"）
3. **内容匹配**：`visualHint` 要体现该页的核心信息，而非通用描述
4. **不含 prompt 咒语**：`visualHint` 是给图库检索 / AI 生图的自然语言描述，不是技术 prompt

---

| bold | 高对比色块、大号加粗文字、警示符号、强调标记 |

## 页面类型 × Layout 组装模板

### 封面页（通常 sparse 布局）

```
[style关键词] 背景，[主视觉焦点]，大字标题「[title]」居中，[装饰元素点缀]，整体[情绪形容词]氛围
```

示例（cute + sparse）：
> 粉色系背景，手绘爱心和星星装饰，大字标题「入冬后脸终于不干了」居中，整体甜美温柔氛围

---

### 内容页 — balanced 布局

```
[style关键词] 图文排版，上方配图占50%，下方文字区域，小标题「[subtitle]」加粗，正文[N]段，[重点词]荧光/加粗标注
```

---

### 内容页 — list 布局

```
[style关键词] 清单风格，竖向排列[N]条目，序号「01/02/03」前缀，每条一行，[图标]装饰，间距均匀整齐
```

---

### 内容页 — comparison 布局

```
[style关键词] 双栏对比，左侧「[A选项]」右侧「[B选项]」，颜色区分两侧，✅❌标记，中间分割线
```

---

### 内容页 — dense 布局

```
[style关键词] 知识卡片风格，[N]个要点紧凑排列，小标题+短说明组合，卡片式分区，信息密度高
```

---

### 内容页 — flow 布局

```
[style关键词] 流程步骤图，步骤「[1→2→3]」箭头连接，每步「[关键词]」，线性流向，清晰编号
```

---

### 内容页 — mindmap 布局

```
[style关键词] 思维导图，中心「[核心词]」，辐射[N]个分支「[分支词]」，层级清晰展开
```

---

### 结尾页（通常 sparse 布局）

```
[style关键词] 收束画面，简洁温暖，CTA文案「[互动引导语]」居中，[互动符号/箭头]，收藏/关注提示
```

---

## 完整示例：notion + knowledge-card preset（5页）

| 页 | Layout | visualHint |
|----|--------|-----------|
| P1 封面 | sparse | notion 极简线条风格，白色背景，手绘框，大字标题「护肤5步法」居中，简洁知性氛围 |
| P2 总览 | dense | notion 知识卡片，5个步骤紧凑排列，序号+手绘图标+短说明，信息密度高，黑白线条 |
| P3 详解 | comparison | notion 双栏对比，左侧「正确做法」右侧「常见错误」，线条分割，✅❌标记 |
| P4 推荐 | list | notion 清单风格，3个推荐产品竖向排列，产品名加粗，适合人群说明，简洁排版 |
| P5 结尾 | sparse | notion 极简收束，一行CTA「先收藏，慢慢看」居中，小箭头指向收藏按钮位置 |
