# 小红书内容分析框架

> 位置：`references/platforms/xiaohongshu/analysis-framework.md`
> 用途：Copy Generation 前的快速内容分析，帮助 Agent 选定 Strategy（A/B/C）、风格和 layout
> 何时读取：Step 5 Copy Generation 开始前，基于 `prompt + sellingPoints + targetAudience` 执行

---

## 一、内容类型分类（7 种）

| 类型 | 定义 | 典型信号词 |
|------|------|-----------|
| **种草** | 分享产品/地点/体验，以推荐为目的 | 强烈推荐、必入、绝了、亲测、种草 |
| **干货** | 提供系统性知识或实用方法 | 攻略、清单、指南、技巧、方法论 |
| **测评** | 多维度评测一个或多个产品 | 横评、对比、测试、优缺点、值不值 |
| **教程** | 分步骤教会用户完成某件事 | 手把手、教程、步骤、如何、一学就会 |
| **避坑** | 警示踩坑经历，帮读者规避风险 | 避坑、血泪史、不要买、后悔了、坑 |
| **情绪** | 以情感共鸣或观点表达为核心 | 谁懂、emo、感同身受、太真实了 |
| **选题** | 借热点/趋势/争议引发讨论 | 最近发现、为什么、你们觉得、争议 |

---

## 二、内容类型 → Strategy 自动映射

| 内容类型 | 推荐 Strategy | 理由 |
|---------|-------------|------|
| 种草、情感、故事、个人经历 | **A（故事驱动）** | 素人感 + 情绪共鸣是小红书种草核心 |
| 干货、测评、教程、清单、避坑 | **B（信息密集）** | 价值优先，读者来此收藏/执行 |
| 高颜值产品、旅行、穿搭、美食氛围 | **C（视觉优先）** | 视觉冲击优先，文字极简 |
| 混合内容 | 看 `sellingPoints` 主线决定 | 若以情感为主 → A；以信息为主 → B |

---

## 三、受众与痛点分析

分析以下三个维度：

1. **谁会点进来**：年龄/性别/消费阶段/使用场景（如：20-28岁女性，刚开始护肤）
2. **他们在找什么**：具体需求或问题（如：找平价好用的保湿面霜）
3. **损失厌恶信号**：是否含有避雷/维权/踩坑元素 → 触发「损失厌恶」 → 点击率显著提升

---

## 四、Hook 潜力评估（5 种注意力屏障突破方向）

| Hook 类型 | 适用场景 | 示例 |
|----------|---------|------|
| **数字型** | 清单/干货/测评 | "5款平价精华横评，第3款绝了" |
| **痛点型** | 种草/情感/避坑 | "入冬后脸干到起皮，终于找到解法" |
| **悬念型** | 种草/选题 | "这个成分 99% 的人用错了" |
| **对比型** | 测评/避坑/教程 | "花 500 和花 5000 护肤的区别" |
| **疑问型** | 情绪/选题/干货 | "为什么你总是攒钱失败？" |

---

## 五、互动预期分类

| 互动类型 | 对应内容 | 引导方式 |
|---------|---------|---------|
| **收藏型** | 干货/清单/教程/测评 | "先收藏，迟早用得上" |
| **评论型** | 情绪/观点/争议/选题 | "你们觉得呢？" / "你是哪种？" |
| **转发型** | 强共鸣/有用/避坑 | "转给需要的人" / "@你那个朋友" |
| **关注型** | 系列内容/专业账号 | "关注我，持续更新" |

---

## 六、快速分析输出模板

Agent 在 Copy Generation 前，用以下格式完成内部分析（不输出给用户，仅用于决策）：

```
内容类型：[种草/干货/测评/教程/避坑/情绪/选题]
目标人群：[简短描述，如 "20-30岁女性，关注性价比护肤"]
Hook 方向：[数字型/痛点型/悬念型/对比型/疑问型] + 拟标题草稿
互动预期：[收藏型/评论型/转发型/关注型]
推荐 Strategy：[A/B/C]，理由：[一句话]
推荐风格：[style 名]，推荐 preset：[preset 名（如适用）]
```

完成分析后，直接进入文案生成，不需要向用户展示分析过程。
