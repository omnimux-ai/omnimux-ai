## 一、布局类型（单页信息密度）

每页 imageHint 中应体现布局类型，指导排版方向。

### sparse（稀疏留白）

- **信息密度**：极低（1-2 个要点）
- **视觉特征**：大面积留白、单一焦点、文字极少
- **最佳页面位置**：封面页、结尾 CTA 页
- **排版建议**：一句话大标题 + 一张主图，不加多余元素

### balanced（均衡标准）

- **信息密度**：中等（3-4 个要点）
- **视觉特征**：图文比例均衡、清晰的视觉层级
- **最佳页面位置**：内容页（最通用）
- **排版建议**：标题 + 正文段落 + 配图，标准图文排版

### dense（知识密集）

- **信息密度**：高（5-8 个要点）
- **视觉特征**：信息卡片风格、紧凑排列、小字多内容
- **最佳页面位置**：干货内容页、对比信息页
- **排版建议**：多条目紧凑排列、图标 + 短文字组合、卡片式布局

### list（列表清单）

- **信息密度**：中高（4-7 条目）
- **视觉特征**：编号/项目符号、逐条排列、一目了然
- **最佳页面位置**：推荐清单、步骤拆解、注意事项
- **排版建议**：序号 + 每条一行、图标前缀、间距均匀

### comparison（对比布局）

- **信息密度**：中等（2 组对比）
- **视觉特征**：左右或上下分栏、明确的对比标签
- **最佳页面位置**：优缺点对比、前后对比、方案对比
- **排版建议**：两栏分割、✅/❌ 标记、色彩区分两侧

### flow（流程步骤）

- **信息密度**：中等（3-6 步）
- **视觉特征**：箭头连接、步骤编号、线性流向
- **最佳页面位置**：教程步骤、操作流程、时间线
- **排版建议**：步骤编号 + 箭头方向 + 简短说明

### mindmap（思维导图）

- **信息密度**：中高（4-8 分支）
- **视觉特征**：中心辐射、分支结构、层级展开
- **最佳页面位置**：知识框架、全景总览、关系梳理
- **排版建议**：中心关键词 + 辐射分支 + 关键词标注

### quadrant（四象限）

- **信息密度**：中等（4 区域）
- **视觉特征**：十字分割、四格分区、标签明确
- **最佳页面位置**：分类汇总、场景矩阵、优先级划分
- **排版建议**：四格均分 + 每格标题 + 简要内容

## 二、大纲策略（多页叙事结构）

Agent 根据内容类型推荐策略，或生成多种策略供用户选择。

### Strategy A: Story-Driven（故事驱动）

- **核心逻辑**：个人经验为主线，情感共鸣优先
- **特征**：从痛点出发，展现转变过程，强调真实感
- **适用内容**：种草体验、个人分享、变化对比、使用感受
- **典型结构**（5 页示例）：

| 页码 | 角色 | 布局 | 内容 |
|------|------|------|------|
| P1 | 封面 | sparse | Hook：痛点共鸣（"入冬后脸不干了🥹"） |
| P2 | 痛点 | balanced | 之前的困扰和失败尝试 |
| P3 | 发现 | balanced | 发现产品/方法的契机 |
| P4 | 体验 | balanced/dense | 使用感受、效果细节 |
| P5 | 结论 | sparse | 总结 + CTA |

- **推荐风格**：warm、cute、fresh

### Strategy B: Information-Dense（信息密集）

- **核心逻辑**：价值优先，高效传递信息
- **特征**：结构清晰、要点明确、专业可信
- **适用内容**：教程攻略、对比测评、清单推荐、知识科普
- **典型结构**（5 页示例）：

| 页码 | 角色 | 布局 | 内容 |
|------|------|------|------|
| P1 | 封面 | sparse | Hook：价值承诺（"5 款平价精华横评"） |
| P2 | 总览 | list/dense | 核心结论或全览表 |
| P3 | 详解 | dense/comparison | 逐项详细对比 |
| P4 | 推荐 | list | 推荐排名或最终建议 |
| P5 | CTA | sparse | 互动引导 + 收藏提醒 |

- **推荐风格**：notion、minimal、chalkboard

### Strategy C: Visual-First（视觉优先）

- **核心逻辑**：视觉冲击为核心，文字极少
- **特征**：大图驱动、氛围感强、即刻吸引
- **适用内容**：高颜值产品、旅行风景、穿搭展示、氛围感内容
- **典型结构**（4 页示例）：

| 页码 | 角色 | 布局 | 内容 |
|------|------|------|------|
| P1 | 封面 | sparse | 主视觉大图 + 一句话标题 |
| P2 | 细节 | sparse/balanced | 产品/场景细节特写 |
| P3 | 氛围 | sparse | 生活场景/使用场景 |
| P4 | CTA | sparse | 简短总结 + 互动引导 |

- **推荐风格**：bold、pop、retro
