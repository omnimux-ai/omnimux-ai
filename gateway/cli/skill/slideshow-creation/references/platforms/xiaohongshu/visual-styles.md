# 小红书视觉风格库

> 位置：`server/skills/slideshow/slideshow-creation/references/platforms/xiaohongshu/visual-styles.md`
> 用途：指导 Agent 在图文创作中选择视觉风格，影响 imageHint 和整体视觉调性
> 来源：适配自 baoyu xhs-images 风格体系

---

## 使用方式

1. Agent 在 `strategyAgent` 阶段根据内容信号选择风格
2. 选定风格后，整套图文的所有页面保持同一风格（视觉一致性）
3. 风格影响 imageHint 的方向词、色彩描述、排版建议

---

## 风格定义

### 1. cute（甜美少女）

- **视觉特征**：粉色系、爱心装饰、圆角气泡、手绘星星、柔软质感
- **适用场景**：美妆、护肤、穿搭、女生日常、恋爱
- **配图方向**：柔和粉色背景、可爱手绘贴纸点缀、圆角卡片、少女风排版
- **经典小红书调性**：最原生的小红书风格

### 2. fresh（清新自然）

- **视觉特征**：白绿色调、植物元素、干净留白、自然光感
- **适用场景**：健康饮食、运动健身、有机生活、环保
- **配图方向**：清爽白色或浅绿背景、叶片/植物装饰、明亮自然光

### 3. warm（温暖治愈）

- **视觉特征**：暖黄/奶油色调、柔和光影、圆润字体、温馨氛围
- **适用场景**：生活记录、美食分享、亲子内容、情感故事
- **配图方向**：暖色调背景、柔光效果、手写体文字、温馨生活场景

### 4. bold（强冲击力）

- **视觉特征**：高对比色块、大号加粗文字、警示符号、强调标记
- **适用场景**：避坑指南、重要提醒、对比测评、紧急通知
- **配图方向**：红色/黄色警示色、大字标题、感叹号/警告图标、高对比排版

### 5. minimal（极简高级）

- **视觉特征**：大量留白、极细线条、单色系、高级感排版
- **适用场景**：高端产品、设计分享、极简生活、品牌推荐
- **配图方向**：白色或浅灰背景、极简排版、少量文字、质感产品特写

### 6. retro（复古怀旧）

- **视觉特征**：褪色胶片色调、复古字体、做旧纹理、怀旧元素
- **适用场景**：穿搭vintage、老物件、怀旧话题、复古潮流
- **配图方向**：暖黄褪色滤镜、复古排版、老式装饰元素、胶片颗粒感

### 7. pop（活力潮流）

- **视觉特征**：高饱和撞色、几何色块、波普元素、动感排列
- **适用场景**：潮流穿搭、新品发布、年轻人话题、趣味内容
- **配图方向**：鲜艳撞色背景、几何形状装饰、活泼动态排版

### 8. notion（知识极简）

- **视觉特征**：极简线条手绘、黑白为主、偶尔单色点缀、知性排版
- **适用场景**：知识干货、效率工具、SaaS推荐、读书笔记、思维模型
- **配图方向**：白色背景、线条手绘图标、清晰的信息层级、Notion 风格排版

### 9. chalkboard（黑板教育）

- **视觉特征**：深色背景、彩色粉笔线条、手写体、教室黑板质感
- **适用场景**：教程、知识科普、学习方法、考试技巧
- **配图方向**：深绿/深灰黑板背景、彩色粉笔手写风格、教育图标

### 10. study-notes（手写笔记）

- **视觉特征**：方格/横线纸背景、蓝色圆珠笔手写、红色批注、黄色荧光标记
- **适用场景**：学习笔记、知识总结、考试攻略、读书摘录
- **配图方向**：仿真笔记纸背景、手写体文字、荧光笔标注、便利贴装饰

### 11. screen-print（网版印刷）

- **视觉特征**：大胆海报艺术、网版印刷半色调纹理、有限色彩、符号化叙事、强对比块面
- **适用场景**：影评、书评、观点文章、海报风封面、文化评论、大片感内容
- **配图方向**：粗粒纹理背景、强对比块面色彩、符号化图形、印刷风排版、有限色调（2-3色）
- **经典调性**：艺术性、戏剧感、观点鲜明

## 内容信号 → 风格推荐

| 内容信号 | 推荐风格 |
|---------|---------|
| 美妆、护肤、穿搭、少女、恋爱 | cute |
| 健康、运动、有机、清爽、自然 | fresh |
| 生活、美食、亲子、情感、温馨 | warm |
| 避坑、警告、对比、重要、必看 | bold |
| 高端、设计、品牌、极简、质感 | minimal |
| 复古、vintage、怀旧、老物件 | retro |
| 潮流、新品、趣味、年轻、活力 | pop |
| 干货、效率、工具、思维、知识 | notion |
| 教程、科普、学习、课堂、方法 | chalkboard |
| 笔记、总结、考试、读书、摘录 | study-notes |
| 影评、书评、观点文章、海报、文化评论 | screen-print |
| 默认（无明确信号） | 根据 slideType 决定：educational→notion, personal→warm, marketing→bold |
