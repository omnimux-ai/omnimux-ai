# 抖音图文 Overlay

用途：在 `slideshow-creation` 已激活后，为抖音图文补充平台差异规则。

## 何时读取

- `targetPlatform/platform/platformHint` 明确是 `douyin`
- 用户明确要求“抖音图文/抖音封面标题/抖音爆点节奏”

## 深度参考（按需读取）

| 文件 | 何时读 |
|------|--------|
| `references/platforms/douyin/skill-context.json` | 任何 Douyin 图文创作，补充平台画像与常见分发信号 |
| `references/platforms/douyin/抖音找选题技巧.md` | 需要强化选题角度、爆点切入或热点借势时 |
| `references/platforms/douyin/抖音图文视觉钩子策略.md` | 生成封面/首屏视觉方案、需要更强停留钩子时 |
| `references/platforms/douyin/抖音图文轮播叙事节奏.md` | 规划多页轮播节奏、每页推进关系与结尾 CTA 时 |
| `references/platforms/douyin/抖音图文文案与搜索策略.md` | 优化标题、字幕、关键词与搜索分发词时 |

## 边界

- 这是平台 overlay，不是主 workflow
- 不能替代 `slideshow-creation`
- 不负责 ask_user / 研究 / 配图 / persist 的主顺序决策

## 平台差异规则

### 文案调性

- 更强调“短、直、快”的信息投递，不要铺垫过长
- 允许更强的结论先行、反差表达和结果承诺
- 封面与标题优先突出问题、收益、变化结果

### 页面节奏

- 首页必须在极短时间内给出冲突、反常识或明确收益
- 中间页保持高信息密度，一页只讲一个推进点
- 抖音图文更接近“可滑动的信息卡片”，不是长笔记，也不是口播提词器

### 标题与封面

- 标题和封面文案都要更直接、更抓眼
- 优先“反差/问题/收益/结论”结构，避免温吞总结句
- 封面文案承担停留责任，标题承担补充搜索与说明责任

### 视觉提示

- `visualHint` 应体现大字标题、强对比、焦点明确
- 更适合 before/after、步骤拆解、结果展示、冲突式排版
- 避免小红书式过重的笔记感留白和生活方式展示

## 输出检查

- 是否在第一页就给出继续看的理由
- 是否每页只承载一个最小结论
- 是否避免了长段解释型表达
- 是否保留了抖音需要的强节奏与强对比
