# 抖音图文轮播叙事节奏

抖音图文不是长笔记，也不是把视频脚本切成几张图。
它更像一组连续滑动的信息卡片：每一页都要给用户一个继续往后看的理由。

## 通用结构

推荐优先采用 5 页骨架：

| 页码 | 角色 | 任务 |
| :--- | :--- | :--- |
| P1 | Hook | 抛出痛点、承诺或反差，先把人留下 |
| P2 | Retention | 立刻给出第一个有效信息，证明不是标题党 |
| P3 | Value | 交付核心干货、关键步骤或核心反转 |
| P4 | Sub-Value | 补充第二层信息、案例或细节 |
| P5 | CTA | 给出收藏、关注、评论或下一步动作 |

## 页面拆分原则

### 1. 一页只讲一个点

- 如果一个页面需要用户停下来读一大段，说明拆分失败
- 一页只保留一个最小结论、一步动作或一个对比画面
- 复杂流程要拆成连续页，不要硬塞在同一页

### 2. 第二页必须马上兑现一点价值

- 第一页只负责钩子，不足以建立信任
- 第二页要马上给出一个明确有用的信息
- 否则用户会觉得“只是标题写得好”，很容易划走

### 3. 结尾页不要只做总结

- 末页要明确告诉用户下一步做什么
- 适合的 CTA：
  - `先收藏，照着做`
  - `评论区回你模板`
  - `关注看下一篇`

## 常见图文结构模板

### 教程型

- P1：结果承诺
- P2：准备项
- P3：步骤 1
- P4：步骤 2 / 结果展示
- P5：收藏 CTA

### 种草型

- P1：理想状态 / 人设钩子
- P2：使用场景
- P3：关键卖点
- P4：前后对比 / 细节补充
- P5：行动 CTA

### 观点型

- P1：尖锐观点
- P2：先给一个核心理由
- P3：再补一个反常识点
- P4：举例或对比
- P5：引导讨论

## 视觉连贯性

- 尽量保持同一组素材的光线、色调、出镜人一致
- 跨页之间保持阅读路径连续，不要每一页都像完全无关的新帖子
- 若有前后对比或步骤递进，要让用户明显感到“下一页会补全上一页”

## 叙事自检

- 第二页是否已经交付真实价值
- 是否每页只有一个最小信息块
- 末页是否给了明确动作，而不是空泛结束
