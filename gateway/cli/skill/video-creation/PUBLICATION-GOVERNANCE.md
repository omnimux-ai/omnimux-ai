# Video Creation Publication Governance

## Decision

`video/video-creation` remains a public business skill because its primary value is video creative direction, prompt planning, model-selection judgment, generation decisioning, and completion-evidence discipline.

It is not treated as a code-execution skill.

## Runtime Boundary

Runtime-readable file:

- `SKILL.md`

Video generation, model listing, model selection, submit/wait/deliver workflows, and artifact delivery are visible tool capabilities. The skill only explains when they are useful and what evidence is required.

## Public Use Conditions

- Use for video plans, video prompt packs, reference analysis, image-to-video planning, direct generation, variants, and video diagnosis.
- Do not select or invent model IDs from memory; use visible model-list/model-selection tools when needed.
- Do not generate video unless the user explicitly requests a video artifact or continuation.
- Do not claim task completion without `taskId`, `videoUrls`/persistent media references, or a clear tool blocker.
