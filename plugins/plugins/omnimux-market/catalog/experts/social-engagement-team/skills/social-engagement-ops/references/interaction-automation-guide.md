# 社媒互动执行与授权指南

仅在用户要求真实互动规划或执行时加载。本文不提供反检测、养号、指纹/IP 轮换、随机间隔或模拟真人动作方案。

## 动作分级

| 类别 | 例子 | 默认处理 |
|---|---|---|
| 只读观察 | 读取用户提供的评论、统计、导出 | 在请求范围内分析 |
| 拟稿 | 评论候选、私信候选、升级话术 | 生成草稿，不发送 |
| 普通账号写入 | 点赞、收藏、关注、评论、私信、转发 | 需精确授权和官方能力 |
| 高风险写入 | 删除、封禁、批量互动、权限/账号设置 | 授权必须覆盖精确对象与影响；已覆盖则不重复询问 |

“分析互动”“给回复建议”“做评论运营方案”均不等于授权真实发布或发送。

## 执行前核对

- 平台与账号；
- 目标内容或用户；
- 动作类型与数量/范围；
- 最终评论或私信正文；
- 是否涉及公开承诺、投诉、订单、退款、法律或隐私信息；
- 授权是否覆盖当前动作；
- 当前运行时是否发现官方 API/连接器及其真实权限。

缺一项且会改变外部结果时才追问。

## 执行流程

1. 先生成目标清单和拟执行 payload。
2. 展示必要的精确预览；只有现有授权未覆盖其对象或影响时才请求确认。
3. 通过官方能力执行，不使用浏览轨迹、随机等待或设备伪装来模拟真人。
4. 遵守平台返回的限流、配额和权限；以官方文档/响应为准，不采用经验“安全上限”。
5. 401/403 时核对原因与现有授权；429 按官方 Retry-After/退避处理。验证码只请求必要的一次性输入，随后继续已授权流程；风控或审核拒绝则停止受限动作，保留错误证据，不换 IP、指纹或账号绕过。
6. 逐项记录 success / failed / skipped 和平台返回标识。

## 禁止

- 未授权批量点赞、关注、评论、私信或转发；
- 自动发现目标后直接触达；
- 多账号协同制造互动；
- 设备指纹、出口 IP、UA、时区或行为轨迹伪装；
- 为绕过审核、验证码、反爬或封禁而改变请求；
- 把发送失败改写成“已完成”。
