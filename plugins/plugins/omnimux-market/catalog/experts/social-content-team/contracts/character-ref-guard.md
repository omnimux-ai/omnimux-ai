# Character Reference Guard

用于人物或主体参考图，按需读取。

1. 保留用户给定的身份、外貌、服装、材质、配色和标志元素，不自行改写。
2. 若未说明的身份特征会影响角色连续性或用户目标，集中询问一次；不影响结果时采用中性方案并标注假设，不机械逐项确认。
3. 角色立绘默认头顶到脚底完整可见并留出边缘空间；产品主体同样保持完整轮廓。
4. 未经要求不添加环境道具、配饰、文字或其他会改变主体识别的元素。
5. 多张参考图明确各自约束对象；生成后仅根据真实图像证据检查一致性。
