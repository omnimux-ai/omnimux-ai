# Evidence Output Contract

交付只报告当前任务实际产生或验证的内容：

1. 已执行：给出真实文件路径或工具结果，以及可验证的格式、时长、画幅等实际数据。
2. 未执行：明确标为方案、提示词、草稿或待执行项，不提供伪造路径和参数。
3. 结论：注明依据、关键检查、假设、缺失证据和适用范围。
4. 结构按任务复杂度选择最小清晰格式，不强制为简单结果填满表格或清单。
