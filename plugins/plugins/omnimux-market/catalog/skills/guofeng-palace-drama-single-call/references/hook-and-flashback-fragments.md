# Hook & Flashback Fragment Library

Reusable opening lines, framings, and flashback constructions for new 国风 palace drama subjects. Each fragment names the *move* first, then gives one or two example lines. Swap the names and the specifics; keep the structural shape. The example lines below are generic templates — invent your own for the actual subject.

## Opening-line archetypes (Beat 1, lands inside 2s)

### 1. The named question
The power-holder uses the subject's full name + a single direct question. Cold, terminal.

- `<女主全名>，那夜竹林，你究竟见了谁？`
- `<男配全名>，你父亲的兵符，是怎么到了北境的？`
- `<女配全名>，这盏茶里的东西，是你放的吧。`

**Move:** Name + temporal/spatial anchor + interrogative noun-phrase. No verbs of accusation — the accusation is implicit.

### 2. The false courtesy
The power-holder opens with a hollow politeness that reads as threat.

- `坐下吧。今夜的话，朕只问一次。`
- `抬起头来。朕想看看，骗朕的人长什么样子。`

**Move:** Imperative softened by 朕/我 + a clause that names the betrayal obliquely.

### 3. The object reveal
The power-holder is holding/looking at an object (letter, hairpin, blade, jade pendant) when the camera arrives. The first line references the object.

- `这枚玉佩，朕记得，是先皇后留给你的。`
- `这封信，写得很用心。可惜，送错了人。`

**Move:** Demonstrative (这/那) + object + one fact that reframes the object as evidence.

## Resistance-line archetypes (Beat 2)

### 1. Formal denial
- `陛下，臣妾不知陛下在说什么。`
- `回陛下，那夜臣妾只是赏竹，并未见任何人。`

### 2. Counter-question
- `陛下既然都知道了，又何必问臣妾？`
- `陛下信谁，自有圣裁。臣妾，无话可说。`

### 3. Detail tell
The line itself is plausible; the visual detail (手指收紧、睫毛轻颤、咽喉滚动) is the betrayal. The beat camera should land on the tell, not the face.

## Flashback insert constructions (Beat 3, ~0.6–1.0s)

The flashback is a single hard-cut insert — no dialogue, color palette flipped to cool (青翠 / 月白 / 玄青), faster camera energy.

### A. Two-figure exchange
Two characters from the reference cast appear in an exterior at night. They exchange one wordless look or one small object (a scroll, a hairpin, a vial). Cut out on the moment of exchange.

- `竹林夜色，月光泛青，<侍卫>与<宫装女子>在竹影下短暂对视，<宫装女子>将一只玉镯塞入<侍卫>掌心，硬切回殿内。`

### B. Single-figure action
One character alone, performing an incriminating action — pouring, writing, opening a door, drawing a blade.

- `回廊月色，<侍卫>独自将一封素笺塞入廊柱缝隙，硬切回殿内。`

### C. Aftermath glimpse
A still or near-still image of the consequence — a spilled cup, a fallen pin, a dark stain — held for ~0.7s.

- `案几特写，一只白瓷茶盏倾倒，茶水浸透素笺一角，硬切回殿内。`

**Rule for all three:** flashback duration in the prose is ~0.8s. No speech. End with `硬切回<location>`.

## Closing-line archetypes (Beat 4 → Beat 5)

### Beat 4 — the trap closes
- `你以为，朕什么都不知道？`
- `朕已经，给过你机会了。`
- `这宫里的事，从来瞒不过朕。`

### Beat 5 — the defiance (or the silence)
- `臣妾问心无愧。`
- `陛下要罚，臣妾领。但臣妾，不曾负陛下。`
- *(or: no line — hold on her eyes, one slow breath, freeze.)*

The silent close is often the strongest. Use it when the user wants maximum tension carryover into a follow-up post.

## SFX punctuation vocabulary

One per beat. All diegetic. Pick from:

- **Interior, fire:** 烛芯爆响 · 烛火轻颤 · 炭盆噼啪
- **Interior, fabric/body:** 衣袍布料摩擦 · 衣袖轻扫 · 跪垫闷响
- **Interior, architecture:** 殿门铜环轻响 · 殿门低响 · 木门吱呀 · 帘幔轻拂
- **Exterior, palace:** 檐角风铃 · 夜风过檐 · 更鼓一响 · 远处宫漏
- **Flashback, bamboo/garden:** 竹叶沙沙 · 竹竿轻碰 · 石阶脚步 · 远处犬吠

Do not stack more than two SFX in any single beat. Beat 3 (flashback) gets exactly one nature SFX (`竹叶沙沙` or `脚步` or `更鼓`).

## Costume / hair anchor phrases

When anchoring a character to their ref, attach a one-line costume note. Examples:

- `白色长袍长发` · `玄色绣金龙袍` · `墨色衣冠玉冠束发`
- `红衣长发` · `素白宫装` · `淡青襦裙银步摇`
- `银甲佩刀` · `玄色劲装` · `深紫宫装珍珠抹额`

Keep it to ≤6 Chinese characters. The reference image carries the actual detail; the phrase only helps the engine route the right ref to the right name.
