# PT-BR Script Template & Hook Library

## Master Script Template

```
[Scene 1 — Hook + Quality Callout ~20 words]
"Procurando o/a [produto/categoria] definitivo/a de [contexto/uso]?
Olha a qualidade desse/dessa [material/tecido] com [detalhe premium]!"

[Scene 2 — Mechanism Reveal ~12 words]
"Mas o melhor vem agora: [mecanismo de fixação] para você [benefício prático]!"

[Scene 3 — Payoff ~18 words]
"É o/a [resultado visual / nome do produto] com qualidade premium!
[reforço do benefício ou detalhe extra opcional]"

[Scene 4 — CTA ~10 words]
"Garanta o seu kit nas principais lojas online!"
```

**Pacing check:** 2.5 w/s target
- Scene 1 (8 s): ~20 words ✓
- Scene 2 (5 s): ~12 words ✓
- Scene 3 (9 s): ~22 words ✓ (slight push allowed — payoff beat)
- Scene 4 (5 s): ~10 words ✓ (or mute entirely, let pill carry it)

---

## Hook Variants (swap into Scene 1)

| Hook type | Template | When to use |
|-----------|----------|-------------|
| **Interrogativo-desejo** | "Procurando o [X] definitivo de [Y]?" | Default — works for most kit products |
| **Interrogativo-presente** | "Ainda não sabe o que presentear para o fã de [X]?" | Gift/seasonal campaigns |
| **Stat shock** | "Esse kit tem [N] peças por menos de [preço]." | Price-competitive products |
| **Before/after split** | "Comum vs. incrível — qual você escolhe?" | Visual contrast products |
| **POV** | "POV: você acabou de encontrar o melhor kit de [categoria]" | TikTok-native, younger audience |

## CTA Variants

| Urgency level | Text |
|---------------|------|
| **High (default)** | `COMPRE AGORA – ESTOQUE LIMITADO` |
| **Medium** | `GARANTA O SEU – FRETE GRÁTIS` |
| **Soft** | `VER NAS LOJAS` |

Default to High urgency for Brazilian marketplace formats unless the brand explicitly requests softer close.

---

## Accent Color Defaults

Pick the CTA pill and kit-description colors from the product's own theme. When the kit has no strong color identity, use a high-saturation pill against a high-contrast description text. Common starting points:

| Kit theme | CTA pill color | Kit description color |
|-----------|---------------|----------------------|
| Costume/heroic | Vivid Red `#CC0000` | Bright Yellow `#FFDD00` |
| Dark/tactical | Dark Gold `#B8860B` | White `#FFFFFF` |
| Gaming | Neon Green `#39FF14` | White `#FFFFFF` |
| Outdoor/Adventure | Safety Orange `#FF6600` | White `#FFFFFF` |
| Neutral/Fashion | Product primary | White or light neutral |
