# Offer Badge Style Guide

## The Hand-Drawn Sticker Rule

Offer badges in this pattern must feel like a sticker someone physically placed on the ad — not a designed UI element.

### Required characteristics
- **Shape:** Starburst, sunburst, or burst — not circle, not pill, not rectangle
- **Edges:** Imperfect, slightly uneven points — feels hand-cut, not vector-perfect
- **Rotation:** 3–8° off-axis — never perfectly horizontal/vertical
- **Placement:** Corner or overlapping product/image edge — organic, not centered or symmetrically placed
- **Shadow:** Subtle drop shadow or slight texture to lift it off the background

### Typography inside badges
- Bubbly, rounded, slightly handwritten-feeling font — this is the ONLY place in the ad where this type style is allowed
- High contrast (white text on teal or pink background)
- Keep copy short: 2–4 words max + optional emoji

### Color assignments
| Offer type | Badge color |
|------------|-------------|
| Free gift | Soft teal |
| % discount | Warm pink or warm burst |
| Bundle/value | Cream/gold accent |

> Match the exact accent hues to the brand's own palette — do not hardcode hex values here.

### Hard no
- Clean corporate pill shape → rejected
- Perfectly centered on the ad → rejected
- Same badge style as a UI button → rejected
- Dollar amount pricing → rejected (use % off or "Free Gift" only)
