# Camera Vocabulary — 5 validated modes + tutorial mode

Not every motion design reel requires the same camera language. Genre dictates pace. Choose the right set of keywords for the mood.

## Quick-pick — signature named moves by mode

Scan this table FIRST, pick 3-6 moves for the reel (one per shot, no two adjacent shots same move), then read the mode section below for full vocabulary and pairing rules.

| Mode | Signature named moves (use one per shot — pick PRIMARY by default, never the FALLBACK without strong reason) |
|---|---|
| **1. Slow elegant** | **PRIMARY (non-Z-axis, use by default):** `Floating crane lift 8cm vertical rise` (Y-axis) · `Surgical crane descent 4cm` (Y-axis) · `Micro orbital arc 8°` (orbital) · `Drift lock-on` (camera holds, only micro horizon tilt 1-2°) · `Lateral parallax dolly 5cm side track` (X-axis). **VALID FALLBACK (Z-axis with discipline — always include cm distance + parallax FG/MG/BG):** `Imperceptible dolly push-in 3-5cm over 2.5s with parallax 100/75/50` · `Breathing dolly 1-2cm in/out synced to subject inhale-exhale, parallax 100/75/50`. Variety rule: no two adjacent shots both use Z-axis. |
| **2. Hyperkinetic chaos** | **PRIMARY (non-Z-axis, use these by default):** `HYPERKINETIC ORBITAL SWEEP` (orbital lateral) · `HYPERKINETIC SPIN-OUT` (barrel-roll 360° — orbital) · `DROP-DIVE PAST` (Y-axis vertical plunge) · `MATCH-FRAME SWING` (orbital pendulum) · `WHIP-PAN SMEAR` (X-axis horizontal punch). **EXPLICIT Z-AXIS FRAMINGS (Z-axis allowed, but requires literal dramatic phrasing):** `VERTIGO PULL` (must include "Hitchcock dolly-zoom — camera tracks back AND zooms in simultaneously, perspective stretches") · `SHATTER PUSH-THROUGH` (must include "camera punches through glass/membrane, fragments fly past lens") · `CRASH-OUT REVEAL` (extreme close-up snaps to wide context in 0.4s). **DEMOTED (Seedance reads as plain zoom — avoid):** ~~`HYPERKINETIC DOLLY-THROUGH at LIGHTNING SPEED`~~ · ~~`Speed ramp slow-mo → fast`~~. |
| **3. Motion-control roboarm** | `Bot&Dolly snap` (programmed move terminates with frame-perfect snap, no overshoot) · `Programmed orbital sweep 90° at constant velocity` · `Mechanical lift-and-rotate 45°` (orbital + Y combined) · `Surgical push-through morph` (Z-axis but explicit "punches through" framing). DEMOTED: ~~`Z-axis travel through`~~ — same Seedance zoom default issue, replace with explicit `DRAMATIC PUSH-THROUGH [foreground element]` framing. |
| **4. Circular orbital** | `Circular dolly-orbit in 90° arc` · `Circular spiral dive` · `Circular orbital tumble 360°` (all orbital — no Z-axis issues) |
| **5. Liquid illustrated** | `Camera HOLDS — elements animate within frame` · `Subtle paper texture breathing` · `Focal plane travels FG to BG` (camera static — internal motion only, no Z-axis camera travel) |

**Match-cut transitions between shots** (premium signature) — pick one type per transition, see "Dramatic Match-Cut Transitions" section below for full vocab: `DRAMATIC PUSH-THROUGH` · `DRAMATIC COLLAPSE` (vanishing point) · `DRAMATIC OBJECT MORPH` · `DRAMATIC UNFURL` · `DRAMATIC LIGHT SWEEP`.

## Universal rule across all modes — PARALLAX when camera moves

When the camera moves through space (push-in / pull-back / orbit / dolly-through / tilt-and-track), foreground / mid-ground / background planes MUST drift at different speeds. Specify in the prompt explicitly per shot. Pick a parallax strength preset that matches the mode:

| Preset | FG / MG / BG drift | Use when |
|---|---|---|
| **Aggressive parallax** | `100% / 40% / 15%` | Hyperkinetic chaos — strong depth differential, hyperkinetic depth feel |
| **Cinematic parallax** | `100% / 60% / 25%` | Default for any moving camera — feels naturally cinematic |
| **Subtle parallax** | `100% / 75% / 50%` | Slow elegant — gentle depth, premium calm |

Without parallax, all planes lock together → flat 2D feel even with motion blur. Mode 5 (Liquid Illustrated Motion) is the exception — camera holds steady, no parallax needed because elements animate within the frame instead.

## Mode 1: Slow Elegant Cinematic

**When to use:**
- Premium product launches (luxury watches, smart rings, premium tech)
- Apple Keynote / Apple TV+ trailer aesthetic
- Halftone B&W meditative reels
- Brand-heritage / editorial fashion
- Wellness / mindful brand reels
- Any content where you need a "premium calm" feeling

**Vocabulary (PRIMARY non-Z-axis terms first):**
- Slow elegant cinematic camera
- Smooth crane sweep (Y-axis vertical)
- Floating crane lift / Surgical crane descent (Y-axis)
- Micro orbital arc (orbital lateral)
- Lateral parallax dolly (X-axis side track)
- Drift lock-on (camera static + internal subject motion)
- Slow contemplative pace
- Steady operator, NO shake
- Apple keynote production value
- Slow Hollywood-grade Cinema 4D
- Subtle parallax on layered elements
- Meditative cinematography

⚠️ **DEMOTED Z-axis vocabulary** — Seedance reads these as generic zoom default. Use ONLY inside DRAMATIC PUSH-THROUGH or VERTIGO PULL framings, never as primary motion phrase:
- ~~Slow gentle push-in~~ (Z-axis = zoom default)
- ~~Soft pull-back~~ (Z-axis = zoom default)
- ~~Gentle drift~~ (when "drift" implies Z-axis forward motion)

**Premium named moves (PRIMARY non-Z-axis first — use these by default; Z-axis demoted at bottom):**
- `Floating crane lift: slow 8cm vertical Y-axis rise over 3s, all planes parallax-separated (FG 100% / MG 75% / BG 50%), subject reframes from low to centre`
- `Surgical crane descent 4cm vertical Y-axis drop over 2.5s`
- `Micro orbital arc 8° around subject — orbital lateral, motion registers only by final frame`
- `Lateral parallax dolly 5cm X-axis side track over 2.5s, depth differential FG/MG/BG`
- `Drift lock-on: camera holds steady at fixed distance, subject locked at golden ratio composition, only micro horizon tilt 1-2° registers — internal subject motion (rotation/scale-shift) provides energy`
- `Slow programmed tilt-up 2-3°, motion-control precision (Y-axis micro tilt)`

**FALLBACK Z-axis moves** (acceptable for Mode A when X/Y/Orbital don't fit — keep tight discipline on cm distance + parallax to avoid crash-zoom collapse):
- `Imperceptible dolly push-in 3-5cm over 2.5s with parallax differential FG 100% / MG 75% / BG 50%, motion registers only by final frame` — valid optional. The cm specification + parallax differential keeps Seedance from defaulting to generic zoom.
- `Breathing dolly: 1-2cm in/out cycle synced to subject inhale-exhale, parallax FG 100% / MG 75% / BG 50%` — valid for intimate Mode A presence shots. Always pair with parallax spec.

**Variety constraint:** even when Z-axis fallback is used, no two adjacent shots can both use Z-axis travel. Mix Y-axis crane / X-axis lateral / Orbital between any Z-axis shots.

When the brief demands Z-axis camera travel for narrative depth/architectural reveal — prefer the explicit dramatic framings: `DRAMATIC PUSH-THROUGH [foreground element]` (Mode 2) or `VERTIGO PULL Hitchcock dolly-zoom` (Mode 2). These have visual signatures Seedance renders distinctly from generic zoom.

**Don't mix with:**
- Whip-pans (kills the calm)
- Stutter cuts (breaks meditation)
- Speed ramps (too aggressive)

**Validated on:**
- Halftone B&W "Create with no limitations" reel
- Premium product reels (smart ring, watch)
- Brand-heritage editorial

## Mode 2: Hyperkinetic Chaos

**When to use:**
- Max chaos brand reels (sport, gaming, AI tech)
- Marvel intro / Cyberpunk 2077 trailer / Edgar Wright cuts
- ASCII chaos productivity reels
- High-energy product launch (sneakers, fitness, beverages)
- Pixel art tech reels
- When you need a "wake up viewer" energy

**Vocabulary:**
- Hyperkinetic cinematic fly-throughs
- Camera dives THROUGH elements
- Camera PUNCHES THROUGH
- Violent whip-pan transitions with extreme motion blur
- Camera barrel-rolls
- Orbital sweeps
- Speed ramps slow-mo → LIGHTNING FAST
- Stutter cuts with brief time-freeze
- Frenetic energy throughout
- DRAMATIC FAST cinematic motion (NOT random handheld shake)

**Premium named moves (use these explicitly in shot specs):**
- `VERTIGO PULL: camera tracks BACKWARD while ZOOMING IN, subject locked in frame while background WARPS and stretches behind it — disorienting depth distortion (Hitchcock dolly-zoom)`
- `CRASH-OUT REVEAL: extreme close-up snaps to wide context in 0.4s, scene depth explodes outward, hard pull-back accelerating from 0 to lightning speed`
- `SHATTER PUSH-THROUGH: camera punches forward through [glass/ice/membrane], explosive shatter at impact, fragments flying past lens with motion blur`
- `DROP-DIVE PAST: camera plunges vertically downward past the [subject] from above, motion blur on edges, gravity-fall feel`
- `MATCH-FRAME SWING: camera pendulums in arc across frame, motion blur tail trailing the swing direction, settles on framing match`
- `HYPERKINETIC SPIN-OUT: camera barrel-rolls 360° with axis offset from subject, subject stays anchored center-frame while environment whirls around it`
- `HYPERKINETIC SLOW-PUSH-IN ramped to fast at speed toward [subject], brief stutter-freeze on text settle`
- `HYPERKINETIC ORBITAL [LEFT/RIGHT] SWEEP around the [subject] at speed, [particles/glitch artifacts] whipping past lens`
- `HYPERKINETIC DOLLY-THROUGH the [tunnel/corridor] at LIGHTNING SPEED, [walls/columns] whipping past lens with motion blur — brief stutter-freeze at peak velocity`
- `HYPERKINETIC TILT-UP plus PULL-BACK revealing the full vertical composition, then settles`
- `Speed ramp slow-mo on [bliss/peak/impact] moment then fast [orbit/track]`

**Transitions vocabulary:**
- VIOLENT GLITCH WHIP-PAN with [smear type] and bass impact
- DRAMATIC STUTTER CUT with frame-freeze
- WHIP-PAN TRANSITION with motion blur streaks
- LIGHT BURST WHIP-PAN with rising synth tension
- DRAMATIC LIGHT BURST EXPLOSION with bass drop
- DATAMOSH GLITCH TRANSITION with frame-skip artifacts
- TAPE-STOP SFX on stutter cuts

**Smear types by genre:**
- ASCII / pixel: pixel smear, RGB shatter
- Halftone: chalk smear, halftone smear
- Handdrawn comic: ink-smear, paint-splash
- Tech / glitch: datamosh smear, RGB streaks
- Default: motion blur smear

**Always pair with:**
- Mandatory tail pause 1-1.5s — freeze last frame, no fade-to-black

**Validated on:**
- ASCII productivity reel (hyperkinetic chaos)
- Generic brand reel
- Halftone hyperkinetic combo
- Pixel art Earth reel
- Generic basketball ad

## Mode 3: Motion-Control Roboarm

**When to use:**
- Tech-thriller aesthetic (Black Mirror intro, Squid Game promo)
- Dystopian / surveillance brand reels
- Premium AI / dev tools brand reels
- CRT-glitch tech-thriller
- **Track B Product Commercial (MDC8) — primary mode** for luxury / athletic / tech / editorial product reels (Tom Ford / BMW / ASICS / Bot&Dolly / Buck Studio / Pentagram tier)
- When you need a "mechanically orchestrated" feeling — cold, precise, surgical

**Vocabulary (premium motion-control — Track B foundation):**
- Motion-controlled roboarm camera
- Bot&Dolly Iris robotic arm precision
- Surgically smooth high-speed dolly
- Programmed easing curves
- Computer-precise camera trajectories
- Motion-control overhead boom
- Elegant rotational drift
- Parallax dolly with subtle vertical drift
- Frame-perfect time-freeze
- Mathematically precise dramatic motion
- Mechanically orchestrated camera
- NOT handheld, NOT shaky — but mathematically precise dramatic motion

**Premium named moves (use these explicitly in shot specs):**
- `Bot&Dolly snap: programmed move terminates with frame-perfect snap to anchor position, mechanical precision, no overshoot`
- `Z-axis travel through: surgical push along Z-axis through [window/door/portal/opening], depth-pass in straight line, environment slides past`
- `Programmed orbital sweep 90° around subject at constant velocity`
- `Surgical push-through morph — camera dives forward through [element] into next scene`
- `Mechanical lift-and-rotate 45°, robotic precision`
- `Motion-control overhead boom with rotational drift` (Track B shot 07 god view default)
- `Lateral parallax dolly with subtle vertical drift, programmed easing across 1.5-2s`
- `Surgical crane descent 4cm vertical Y-axis drop with motion-control easing`
- `Programmed easing curve: ease-in-out 0.4s, no overshoot, terminates with frame-perfect snap`

**Distinguishes from hyperkinetic:**
- Hyperkinetic = chaotic energy, can be rough at edges
- Motion-control = clean precision, robotic smoothness
- Same speed, different texture: chaos vs orchestrated

**Always pair with:**
- Audio: subtle electrical hum, tech ambience, CRT scanline crackle (tech-thriller) OR ambient room tone + sharp transitions (Track B product commercial)
- Glass shattering / liquid metal motifs work especially well
- Cool palette (deep blacks, cyans, occasional warm amber accents) for tech-thriller
- Monochrome OR monochrome+neon-accent for Track B athletic
- Pure pitch black void / atmospheric gradient / light gray studio for Track B luxury

**Validated on:**
- CRT-glitch tech-thriller reel
- Generic surveillance / AI brand reels
- Track B Product Commercial (validated through 70+ production gens — STRIDE / AXIS / VAULT / ECLIPSE PRO / AURUM project archive)

**Track B-specific per-shot rule.** ONE clear action + ONE camera move per shot. Not three. Don't combine "rotates while orbits while zooms" → fails. Three slots per shot:
- ACTION: what subject does
- CAMERA: how camera moves (one named move from above)
- LIGHT: what illumination does this shot

Stacking actions or stacking camera moves = fail. ASICS / Bot&Dolly storyboard discipline.

## Mode 4: Circular Orbital

**When to use:**
- Emotional brand arcs (wellness, narrative reels)
- Handdrawn comic style brand reels
- When you need an "embraced by motion" feeling — caring, encompassing
- Reels with emotional payoff (transformation, awakening, journey)

**Vocabulary:**
- Circular orbital arc sweeping around X
- Circular dolly-orbit in 90-degree arc
- Circular sweep arcing past shoulder
- Circular spiral dive following curving path
- Circular orbital tumble rotating 360 degrees
- Camera barrel-rolls through swirling vortex
- Orbital arcs, spirals, sweeps
- Heavy emphasis: "CIRCULAR motion — orbits, arcs, spirals, sweeps, NOT straight tracks"

**Why this distinction matters:**
By default Seedance tends toward straight-line tracks (lateral, push-in, pull-back). To get true orbital motion — you need to explicitly describe "circular", "arc", "orbit" multiple times and explicitly negate "NOT straight tracks".

**Always pair with:**
- Emotional VO (energetic creator OR whispered ASMR — both work)
- Slower transitions between circular shots (whip-pans kill orbital flow)

**Validated on:**
- Handdrawn brand reel (procrastination → creation arc)
- Emotional wellness reels

## Mode 5: Liquid Illustrated Motion

**When to use:**
- Editorial poster animations (Saul Bass / Milton Glaser style)
- Psychedelic ink illustration brand reels
- Screen-print zine aesthetic motion
- A24 visual identity reels
- Woodblock print / 1960s psychedelic illustration motion
- Handdrawn 2D artwork "coming alive"
- When you need a "poster comes alive" feeling, not "camera flies through scene"

**⚠️ Anti-grid caveat (camera-holds-steady).** Because camera does not move through space in this mode, Seedance is prone to preserving the storyboard sheet's panel labels (01, 02, …) verbatim in output frames — there's no camera motion implicitly cropping them out. Every per-shot ANTI-GRID slot MUST include the explicit "Applies even when camera holds steady — Seedance must still crop panel labels out of the output frame" sentence for Mode 5 reels. v1.6.1 R2 (Wild Energy tiger) leaked `02` labels into corners of multiple frames because this caveat was missing. Do not abbreviate the ANTI-GRID slot for Mode 5 / static-camera shots.

**Vocabulary:**
- Liquid ink motion camera
- Ink shapes themselves animate dynamically
- Forms flowing and morphing as if alive within the frame
- Camera HOLDS relatively centered with subtle drift but the SHAPES do the major motion
- Swirling, morphing, expanding, contracting, flowing organically
- Subtle paper texture slight breathing throughout
- NO hyperkinetic camera shake — visual energy comes from ELEMENT MOTION, not camera
- Editorial poster animation aesthetic
- Premium illustrated motion design

**Key conceptual shift:**
Other camera modes — *camera moves through scene*. Liquid illustrated motion — *scene moves while camera holds steady*. This is an inverted philosophy of movement. Used when aesthetic depends on sustained illustrated composition (poster art) that shouldn't "blur" with hyperkinetic camera.

**Element motion vocabulary (what animates):**
- Ink shapes flow into the frame from edges
- Liquid forms swirl and reorganize
- Spirals rotate and pulse with hypnotic motion
- Trails stream behind moving illustrated figures
- Typography pops in with ink-bleed effect
- Paper background subtly breathes
- Shapes morph between scenes

**Always pair with:**
- Strict palette discipline (3-color usually: paper background + main ink color + 1 accent)
- Bold display typography (heavy condensed sans-serif, NOT delicate serif)
- Liquid ink dissolve transitions between shots
- Slower contemplative VO pacing (male gravitas or whispered ASMR work best)

**Don't mix with:**
- Hyperkinetic camera (kills the poster aesthetic)
- Photorealistic elements (breaks illustration consistency)
- Multiple disparate art styles in one reel

**Validated on:**
- Editorial brand reel (psychedelic ink illustration with pink accent)

## Anti-vocabulary (Track B specific — words that produce cheap chaotic feel)

These vocabulary items signal "AI cheap render" and produce frenetic shaky output instead of premium motion-control aesthetic. **Never use as primary motion phrase in Track B Product Commercial prompts.** Track A allows these in Mode B hyperkinetic chaos by design — the ban is Track B-specific.

**Banned vocabulary (Track B):**
- ❌ "Violent crash" — produces frenetic shake instead of motion-control precision
- ❌ "Lightning fast" (overuse) — Seedance reads as crash-zoom default
- ❌ "Random handheld shake" — kills surgical precision
- ❌ Generic "chaos" — no spatial anchor
- ❌ "Motion blur as graphic overlay" — looks like AE preset, not crafted motion design
- ❌ "Light streaks rendered as graphic effect" — 2D effect feel
- ❌ "Speed ramps faked through static motion blur" — cheap-effect signal
- ❌ "Particle trails as 2D overlay" — AE preset feel

**Replacements (use these instead):**
- ✅ "Motion-control precision"
- ✅ "Premium dynamic"
- ✅ "Surgically smooth"
- ✅ "Bot&Dolly Iris robotic arm precision"
- ✅ "Programmed orbital sweep at constant velocity"
- ✅ "Camera-driven push-through with motion blur trail"
- ✅ "Mechanical lift-and-rotate with frame-perfect snap"

The anti-vocabulary list is **Track B-only** because those phrases trigger Seedance's frenetic shaky default response, which mismatches the premium reference-tier register (Tom Ford / BMW / ASICS / Bot&Dolly). In Track A Mode B reels these phrases are sometimes appropriate (sport / gaming / hyperkinetic chaos by design) — context-dependent.

**Cheap-effect signals (what users read as cheap — avoid in any reel):**
- Motion blur as graphic overlay (looks like After Effects preset)
- Light streaks rendered as 2D effect (instead of camera-driven optical flare)
- Generic "kinetic energy" without specific named camera move
- Stock motion graphics vocabulary ("dynamic", "energetic", "powerful" alone, no spatial anchor)

→ Always replace generic kinetic adjectives with named camera moves from this file's mode sections.

## Tutorial Mode (UI walkthroughs)

**When to use:**
- App tutorial / UX walkthrough reels
- Product demo with UI states sequence
- Step-by-step instructional content
- Any content where UI fidelity > camera drama

**Vocabulary:**
- STATIC clean tutorial framing throughout
- NO camera motion, NO orbital camera, NO whip-pans, NO hyperkinetic motion
- Each screen centered fullscreen
- Camera holds steady
- Motion comes from UI itself, not the camera
- Smooth fade-and-slide transitions matching mobile app navigation feel

**UI element animation vocabulary:**
- Tap pointer dot pulses gently 1-2 times

## Dramatic Match-Cut Transitions (premium signature)

Generic whip-pans / glitch wipes — this is default. For premium signature aesthetic use **conceptual match-cut transitions** — each transition has logic, not just visual blur.

**5 validated dramatic transition types:**

### 1. Object morph match-cut
One object morphs through particle/element dissolve into next object. Particles reorganize across the cut.

**Vocabulary:**
- "DRAMATIC MATCH-CUT TRANSITION: the [object A] morphs through [particle/medium] dissolve into [object B], particles reorganizing seamlessly across the cut"

**Example:** Glowing orb morphs into human eye through halftone particle dissolve.

### 2. Push-through dimensional shift
Camera dives forward AND PASSES THROUGH a character/object, emerging into dimensional space behind. Used for surreal/spatial transitions.

**Vocabulary:**
- "DRAMATIC PUSH-THROUGH TRANSITION: camera dives forward AND PASSES THROUGH the [head/body/object] into the dimensional space behind, emerging into [next scene space]"

**Example:** Camera passes through person's head from close-up into hexagonal tunnel space.

### 3. Vanishing point collapse
Tunnel/depth's vanishing point pulls inward and collapses INTO a solid form. Dimensional shift from infinite space to compact object.

**Vocabulary:**
- "DRAMATIC COLLAPSE TRANSITION: the [tunnel/space]'s vanishing point pulls inward and collapses INTO a [solid form/cube] at center, dimensional shift from infinite [space] to compact object form"

**Example:** Hexagonal tunnel collapses into floating geometric cube.

### 4. Geometric morph through medium
Solid form dissolves outward into particles, particles reorganize into next form. Geometric morph through aesthetic medium (halftone, ink, pixels).

**Vocabulary:**
- "DRAMATIC MORPH TRANSITION: the [form A] dissolves outward into [particles/medium], particles reorganize into the shape of [form B], geometric morph through [medium] dispersion"

**Example:** Geometric cube dissolves into halftone particles, reorganize into infinity symbol.

### 5. Unfurl / reorganize transition
Symbol/shape unfurls vertically (or horizontally), particles reorganize into rising column / new composition.

**Vocabulary:**
- "DRAMATIC UNFURL TRANSITION: the [form] unfurls [vertically/horizontally], particles reorganizing into a rising [column/composition], dimensional unfurling into the next composition"

**Example:** Infinity symbol unfurls vertically into rising particle column streaming upward.

### When to use match-cut transitions

**Use when:**
- Premium reel where each transition should have meaning
- Reel uses consistent visual medium (halftone particles, ink, pixels) that allows seamless reorganization
- Reel wants "Apple TV+ trailer" or "Patek Philippe luxury ad" production quality
- Story arc has conceptual flow between shots (not just a feature list)

**Don't use when:**
- Hyperkinetic chaos reel (whip-pans + bass impacts more appropriate)
- Tutorial / UI demo (smooth iOS-native transitions match aesthetic)
- Quick cuts brand reel where each shot stands alone

**Validated on:**
- Premium halftone B&W headphones reel (5 match-cut transitions per reel)
- Brand-heritage editorial with glitch transitions

### Match-cut + camera mode pairing

| Camera mode | Best match-cut transition types |
|---|---|
| Hyperkinetic chaos | Object morph + Push-through (chaos + signature drama) |
| Motion-control roboarm | Vanishing point collapse + Geometric morph (precision) |
| Slow elegant | Object morph + Unfurl (gentle but conceptual) |
| Liquid illustrated motion | Object morph + Geometric morph through ink |
| Circular orbital | Unfurl + Object morph (emotional flow) |

Match-cut transitions **NOT** combined with violent whip-pans / glitch wipes in one reel — it's either one or the other. Mixing destroys signature.

## Camera mode mixing

Pick ONE dominant mode per reel for consistency. Camera tail freeze (1-1.5s static hold on last frame) is independent of mode — applies to every reel as a clean edit handle.

**Common combos:**
- Hyperkinetic chaos + tail freeze (default for brand reels)
- Slow elegant + tail freeze (premium product launches)
- Motion-control roboarm + tail freeze (tech reels)
- Circular orbital + tail static (emotional narrative reels)
- Tutorial static throughout (UI demos)

**Avoid:**
- Mixing hyperkinetic with motion-control in one reel — feels confused
- Slow elegant + speed ramps — kills the calm
- Circular + whip-pans — breaks the orbital flow
