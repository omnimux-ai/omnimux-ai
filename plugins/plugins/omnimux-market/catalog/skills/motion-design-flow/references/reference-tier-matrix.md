# Reference Tier Matrix — 4-Tier Register Selector (v2.0)

When writing boards for any of the 4 modes (MDH / MDT / MDI / MDC8), pick the default-good register from this 4-tier matrix instead of falling through to AE-template kinetic cliché or stock-photography photographic cinema.

**v2.0 critical (HR-3 REALISM BAN):** Motion design is a design discipline. Photographic cinematic register (Tier 4) is **allowed ONLY in MDC8 Product Reel**. For MDH High Motion / MDT Typography / MDI Infographic — Tier 4 is BANNED, no exceptions. The antidote to AE-template / comic-explosion cliché is **premium designed 3D motion graphics** (Tier 1) or **editorial poster** (Tier 2) or **illustrated motion** (Tier 3) — never photographic cinema.

## Per-mode default tier

| Mode | Default tier | Alternative |
|---|---|---|
| **MDC8 Product Reel** | Tier 4 Photographic cinematic (luxury / athletic / tech / editorial premium product) | Tier 1 if brand register is graphic-3D (chrome bottle / sculpted material) |
| **MDH High Motion Reel** | Tier 1 Premium 3D motion design | Tier 3 Illustrated motion (chibi mascot / kawaii CPG / food delivery) |
| **MDT Typography Reel** | Tier 2 Editorial poster (Anthropic-style 2D editorial) | Tier 1 Premium 3D motion design (kinetic display 3D — Sucuk und Bratwurst / Polygon1993) |
| **MDI Infographic Reel** | Tier 1 Premium 3D motion design (chrome data viz) | Tier 3 Illustrated motion (friendly / wellness / education data viz) |

## Tier 1 — Premium 3D motion design (default-good for kinetic / brand reels)

**Aesthetic:** Stylized 3D-rendered material identity with designed lighting, designed motion, strong graphic discipline. Octane / Redshift CGI render tier with deliberate material craft.

**Trigger phrases (English):**
- `kinetic concept reel`
- `premium 3D motion design`
- `designed 3D motion graphics`
- `material identity`
- `stylized 3D`
- `Octane render` / `Redshift render`
- `Buck Studio` / `Buck-style`
- `ManvsMachine` / `Block & Tackle`
- `Sucuk und Bratwurst`
- `Polygon1993`
- `Tendril 3D`
- Brand domains that naturally fit: energy drinks, tech / SaaS, FinTech, fashion drop, music label, AI / cognitive products

**Reference studios:**
- **Buck** (3D work — premium designed materials with character)
- **ManvsMachine** (sophisticated 3D motion with material discipline)
- **Block & Tackle** (broadcast motion design at premium tier)
- **Sucuk und Bratwurst** (designed 3D type + kinetic material studies)
- **Polygon1993** (isometric / abstract 3D material craft)
- **Tendril** (3D work specifically — they do photographic too, pick the 3D side)

**Validated win benchmark:**
- BRAMBLE perfume — thorns as 3D-modeled material identity, purple/yellow disciplined rim lighting, single subject world across 6 panels

**Banned in this tier:**
- AE Pre-comp explosion templates
- Comic-style radial impact bursts
- Halo glow auras around wordmark
- Centered POW-BAM compositions
- Generic Y2K chrome (without brand-DNA specificity)
- Photographic cinema register

## Tier 4 — Photographic cinematic (Product Reel ONLY, v2.0 HR-3)

**Aesthetic:** ARRI Alexa cinematography, 35mm grain, 180° shutter natural motion blur, iPhone editorial register, photographed-not-rendered.

**v2.0 CRITICAL: Tier 4 is allowed ONLY in MDC8 Product Reel.** HR-3 REALISM BAN forbids photoreal humans / documentary register / cinema lens vocabulary in MDH / MDT / MDI. If brief implies Tier 4 register but mode is MDH / MDT / MDI → re-route. Either rework to Tier 1/2/3 stylized register, OR route to Product Reel where Tier 4 is the natural register.

**Trigger phrases (must be EXPLICIT in brief):**
- `documentary brand film`
- `automotive commercial`
- `UGC creator review` — but UGC routes to ugc-flow, not motion-design-flow
- `cinematic narrative brand film`
- `branded documentary`
- `Apple keynote style cinematic`

**When NOT to use this tier (even if it feels right):**
- Energy drink brand reel → use Tier 1 Premium 3D motion design
- Perfume brand reel → use Tier 1 Premium 3D motion design (BRAMBLE benchmark)
- Architecture studio reel → could be Tier 1 (3D-rendered architectural) OR Tier 2 (editorial restraint)
- Music label reel → use Tier 1 with brand-DNA material identity
- Tech / SaaS reel → use Tier 1 or Tier 3 illustrated

**Reference register (when narrowly applicable):**
- ARRI Alexa Mini LF cinematography
- 35mm film grain
- 180° shutter natural motion blur
- Photographic studio lighting
- iPhone editorial register

**Banned even in this tier:**
- Stock photography collage stitched together as concept arc
- Literal photo-real environments cobbled across panels (highway → gamer setup → industrial → rooftop = stock photo collage)
- Cyan/orange AI-CGI sci-fi cliché
- Interstellar generic look

## Selection procedure (v2.0)

1. Identify mode (Step 0a) → look up per-mode default tier in the table at the top of this file
2. If mode = MDC8 Product Reel → Tier 4 default acceptable (the only mode where it is)
3. If mode ∈ {MDH, MDT, MDI} → use mode default OR mode alternative; **NEVER Tier 4** (HR-3 REALISM BAN)
4. If brief domain conflicts with mode default → check alternative tier; if still no fit, ask user

When in doubt within the legal set for the mode: Tier 1 > Tier 2 > Tier 3 priority order for MDH / MDT / MDI.

## Domain overrides (v2.6 — "push diagonal" register for cliché-prone domains)

When SKILL.md Step 0f BRAND-DNA EXTRACTION fires (cliché-prone domain detected) AND user picks "Surprise me — push diagonal from default" — use these overrides instead of domain's AI default:

| Cliché-prone domain | AI default (BANNED without explicit trigger) | "Push diagonal" alternative |
|---|---|---|
| **Energy drink / caffeine / pre-workout** | Chrome can on circuit-board void + electric-cyan voltage current + neon-blue PCB traces | Buck-Studio physical-material craft register — specific physical-substance material world (clay / sand / fabric / wood / stone) carrying the brand identity, NOT digital-electric. Or stylized human-element-focused (specific hand / specific gesture / specific moment-of-use). |
| **Coffee / espresso / dark roast** | Coffee beans on burning embers + amber smoke spirals + dramatic-orange flame on black | Specific brewing ritual / specific origin terroir / specific cup-and-hand human moment / specific paper-and-ink editorial register. NEVER fire-and-amber food-photography. |
| **Tech / SaaS / coding / dev tool** | Neon-circuit-grid + cyan-electric-traces + matrix-glow void | Specific human-element (specific gesture / specific moment) / specific physical-material metaphor (specific tactile substance representing the abstract product). NEVER generic-circuit register. |
| **Streetwear / Gen-Z / urban / chaotic** | Pink-cyan Y2K chromatic aberration + glitch-overlay + graffiti void | Specific cultural sub-scene anchor (specific dance style / specific music genre / specific city) + specific palette that's NOT pink-cyan-Y2K. Maybe earth-tones / unexpected-bright / monochrome-with-one-accent. |
| **Wellness / meditation / mindful** | Cream-gradient + soft-blob pastel + bare-phone-on-void | Specific botanical / specific natural element / specific human ritual that anchors the calm — never bare-phone-on-cream. Botanical illustration ink-on-paper editorial register works (NEST / FIELD benchmark). |
| **Music / DJ / label** | Sine waves / oscilloscope / neon purple+blue (HR-7 existing ban) | Specific vinyl / mixing console / club volumetric / speaker membrane macro. Real brand-world physical substance. |

These overrides are not "always use this instead". They're "use this when user picks Surprise me push diagonal". For other Step 0f outcomes (user provides specific material / specific gesture / specific cultural anchor) → bake user's specific into prompt directly.
