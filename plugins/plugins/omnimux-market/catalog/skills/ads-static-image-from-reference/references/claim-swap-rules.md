# Claim-swap decision checklist

For **every** text block visible in the reference, run this check before you carry it into the new ad.

## Categories of claim and what to verify

| Reference claim type | Examples | Verify against |
|---|---|---|
| Quantitative spec / % | "30% more X", "12-hour battery", "SPF 50" | User's spec sheet / panel printed on the pack |
| Absence / "free-from" status | "Sugar-free", "Fragrance-free", "Caffeine-free" | Ingredients or composition list — look for the disqualifying item |
| Dietary / lifestyle | "Vegan", "Vegetarian", "Plant-based", "Cruelty-free" | Ingredients/material list AND any traces or sourcing note |
| Origin / sourcing | "Made locally", "Organic", "Ethically sourced" | Pack certification marks / origin statement |
| Additive / formulation claims | "No preservatives", "No parabens" | Ingredients list — these items are usually itemized |
| Allergen / safety claims | "Gluten-free", "Hypoallergenic" | Allergen panel + any "may contain traces" statement |
| Format / SKU facts | "Crunchy", "Refillable", "500g pack" | Pack copy / size — these are usually safe to keep |
| Sensory / subjective | "Delicious", "Wonderfully smooth", "Long-lasting" | Generally safe; pull verbatim from the user's product copy if available |

## Decision rule

For each reference claim:

1. **Can I point at a specific source confirming this is true of the user's SKU?**
   - Yes → keep the claim. Use the user's wording if their copy phrases it differently.
   - No → drop it.
2. **Is there a substitute claim from the user's product copy that fits this slot (same character length, same vibe)?**
   - Yes → swap in the substitute.
   - No → use a neutral format claim ("500g pack", "Crunchy", "Refillable") that is unambiguously true.

## Frequent failure modes

- Carrying over a **"vegan" / "cruelty-free"** badge to a SKU whose own panel carries a disqualifying traces or sourcing note. A shared production line can void the claim even when the formula itself qualifies.
- Carrying over an **"no added sugar" / "free-from" status** to a variant that does contain the item. Flavored or premium variants of the same product family often add the very thing the base variant omits.
- Carrying over **percentage / quantitative claims** ("30% protein", "12-hour battery") without checking — different variants of the same product family frequently have different specs.
- Carrying over **certifications** (organic, fair trade, safety marks) the user's SKU does not actually hold.

## Default safe substitutes

Slot-fillers that are almost always true if the pack supports them:
- Net size / count: "500g", "1L", "Pack of 3"
- Format: "Crunchy", "Refillable", "Travel-size"
- Use case: "Great for everyday use", "Perfect for on the go", "Ideal as a gift"
- Quantitative (only if confirmed on pack): "X% more", "X-hour"
