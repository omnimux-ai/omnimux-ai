# Headline library — beat-indexed, 2-line, no-period, no-article

Use these as molds. Swap the verb/noun for the target app. Keep the rhythm.

The rule: max 2 lines, max ~5 words per line, line break at the slash, no terminal punctuation, no leading article. Match the UI language exactly.

## Beat 1 — Entry / login / onboarding

| EN | PT | ES |
|---|---|---|
| Fast start / no friction | Início rápido / sem atrito | Inicio rápido / sin fricción |
| Sign in / in seconds | Entre / em segundos | Entra / en segundos |
| Up and running / instantly | Pronto / em segundos | Listo / al instante |

## Bad headline patterns (do not produce)

- "The easiest way to manage your tasks." — full sentence, terminal period, article.
- "🚀 Get Things Done Faster Than Ever!" — emoji, exclamation, hype voice.
- "Sign in • Track • Confirm • Finalize" — bullet list pretending to be a headline.
- "Download now on Google Play" — CTA copy; the store button is the CTA.
- "5-star rated by 10,000+ users" — proof copy; belongs on the listing page itself, not the card.
