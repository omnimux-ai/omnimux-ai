# 通用商品轮播图示例

## 商品类型

小型家居收纳用品。

## 选择方案

场景解决方案。

## 选择理由

商品价值主要通过摆放位置、使用动作和收纳结果来理解，
不适合连续制作多张相似的棚拍产品图。

## 页面安排

### 第 01 页：商品整体

- 图片类型：商品整体展示
- 销售作用：看清商品外观
- 画面：商品置于简洁桌面中央
- 内部版式：单图
- 图内文案：Clean setup

### 第 02 页：使用场景

- 图片类型：场景使用展示
- 销售作用：理解使用方式
- 画面：商品放置在已确认的使用位置
- 内部版式：单图
- 图内文案：Easy to place

### 第 03 页：结构细节

- 图片类型：局部放大
- 销售作用：看清可见结构
- 画面：放大商品的实际细节
- 内部版式：局部放大
- 图内文案：Detail view

### 第 04 页：摆放结果

- 图片类型：场景完成展示
- 销售作用：展示整理后的视觉效果
- 画面：商品与已确认道具共同出现
- 内部版式：单图
- 图内文案：Made for everyday use
