# Visual Description Lock — per-variant template

Before generating any scene, inspect every uploaded product photo and fill one of
these blocks per variant. Embed the completed block **verbatim** in every scene
handoff that features that variant so the product renders faithfully and identically
across all scenes. This is the single biggest fidelity lever in the pattern.

## Template

```
VARIANT <n> — VISUAL DESCRIPTION LOCK
- Product type & material: <e.g. white glossy ceramic mug, C-handle on right>
- Color story: <base color + accent palette>
- Printed text (verbatim): "<exact wording, line breaks preserved>"
- Printed motif: <e.g. watercolor floral band — peonies + eucalyptus, wrapping front>
- Accent elements: <e.g. two butterflies, blue + amber>
- Shape / handle / lid notes: <handle position, taper, lid, spout>
- Finish: <glossy / matte / satin>
- Background in source photo: <plain white / lifestyle>
- REAL MOTIF MIRROR for this variant: <real element to pair — e.g. fresh peonies in
  matching pink/cream, soft butterfly-toned garden bokeh behind>
```

## Worked example (freshly invented, for a neutral hypothetical product)

```
VARIANT 1 — VISUAL DESCRIPTION LOCK
- Product type & material: white glossy ceramic mug, C-handle
- Color story: white body, soft pink + cream + sage floral, amber/blue butterflies
- Printed text (verbatim): "Bloom Where You're Planted" + a short keepsake line beneath
- Printed motif: watercolor floral band wrapping the front
- Accent elements: butterflies in amber and blue
- Finish: white glossy ceramic
- Background in source photo: plain white studio
- REAL MOTIF MIRROR: fresh peonies + soft garden bokeh color-matched to the print
```

## How to use it

- Paste the relevant variant block into **every** scene direction for that variant.
- Pair it with the instruction: *"Preserve every printed letter, verse, motif and
  accent EXACTLY as in the reference."* — never "no text".
- Keep the **REAL MOTIF MIRROR** line consistent for a variant across its scenes so the
  pairing reads as intentional, not random set dressing.
