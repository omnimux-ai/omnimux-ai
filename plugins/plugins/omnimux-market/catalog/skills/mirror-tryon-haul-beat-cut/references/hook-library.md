# Hook Overlay Library

All hooks below follow the locked format: **one short phrase + one emoji, lowercase, sans-serif, upper third, ~2.5s on-screen, never spoken aloud**. Pick one that fits the brand voice and outfit theme. Never stack two emojis. Never use ALL CAPS.

## Generic haul

- `outfit picks 🤍`
- `new in 🛍️`
- `outfit ideas 🤍`
- `which one? 👀`
- `mini haul ✨`
- `pov: package day 📦`

## Brand-led

- `[brand] haul ✨`
- `everything from [brand] 🤍`
- `tried [brand] so you don't have to 👀`

## Season / occasion

- `summer fits ☀️`
- `fall capsule 🍂`
- `date night options 🍷`
- `wedding guest haul 💐`
- `going-out outfits 🪩`
- `back to office 💼`

## Price / value angle

- `all under $50 💸`
- `affordable finds 🤍`

## Question / engagement bait

- `which one wins? 👀`
- `1, 2, 3, or 4? 💭`
- `comment your fave 👇` *(only acceptable comment-bait; still no spoken CTA)*

## Notes

- If extending duration to act as a CTA (rare, only on user request): `outfit picks — link in bio 🛍️` for ~3.5s. Still no spoken close.
- Avoid: anything > 4 words, double emojis, hashtags inside the overlay, exclamation marks.
