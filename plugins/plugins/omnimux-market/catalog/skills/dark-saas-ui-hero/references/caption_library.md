# Section Caption Library

Per-scene captions for the bottom band. Rule: **4–8 words, describe the action, not the label.** All examples below are invented teaching templates — swap in wording that fits the product, never a real brand name.

## By section type

### Dashboard / overview
- "Your whole pipeline, one glance."
- "Every metric, no spreadsheets."
- "All your work, surfaced instantly."

### Generator / primary action page
- "Type a prompt. Get a result."
- "One input. Infinite variations."
- "From idea to output in seconds."

### Hooks / scripts / copy outputs
- "Scroll-stopping hooks, ready to ship."
- "Voice-matched scripts, written for you."
- "Headlines that test before you spend."

### Creative angles / strategy outputs
- "Every angle, mapped automatically."
- "Positioning decisions, done in minutes."
- "Strategy that used to take a week."

### Concepts / storyboard outputs
- "Concepts you can actually ship."
- "Storyboards, ready for production."
- "From idea to shot list, instantly."

### Launch plan / roadmap / output destination
- "Your full plan, built for you."
- "Day-one to day-thirty, mapped."
- "Everything sequenced. Just hit go."

### Settings / integrations
- "Connects to the stack you already use."
- "Set it once. Runs forever."

### Billing / pricing
- "Pricing that scales with you."
- "Free to start. No card required."

### Onboarding / empty state
- "Up and running in 60 seconds."
- "No setup. No training. Just open."

## Anti-patterns

- ❌ "Ad Hooks" → ✅ "Scroll-stopping hooks, ready to ship."
- ❌ "Dashboard View" → ✅ "Your whole pipeline, one glance."
- ❌ "Settings Page" → ✅ "Connects to the stack you already use."

The label tells the viewer *where they are*. The action caption tells them *why they'd care*. Always pick action.

## Hook line shape (scene 1)

Three fragments, period-separated, total ≤6 words. Pattern: `[trigger] · [magnitude] · [speed]`. All examples are invented — adapt to the product, never reuse a real brand's tagline.

| Product type | Example hook |
|---|---|
| AI generator | "One prompt. Full output. 60 seconds." |
| CRM | "One contact. Whole timeline. Instant." |
| Code review SaaS | "One PR. Every reviewer. Minutes." |
| Health-scan app | "One scan. Full report. Today." |
| Recruiting tool | "One role. Hundred matches. Tonight." |
| Doc-AI / contract review | "One contract. Every risk. Minutes." |
| Analytics | "One query. Every chart. Live." |

Verbs are allowed in fragment 1, banned in fragments 2–3.
