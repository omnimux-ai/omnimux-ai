# In-Game DTC Ad Playbook

A creative playbook for 9:16 video ads built for **mobile in-game interstitial + rewarded-video** ad inventory. Read this before you brief a director, pick a caption preset, or decide where the offer lands in the timeline. The producer / director / mode skills handle tool orchestration — this skill teaches the creative *move*.

## 1. When to use this pattern

Use it when **all** of the following are true:

- The buyer is a cross-border DTC brand (Shopify, TikTok Shop spillover, or independent .com) targeting the US.
- The placement is **mobile in-game interstitial or rewarded video** — full-screen unskippable interstitial or rewarded video inside mobile games, with a 5–15s non-skippable countdown and ~35s average impression time.
- The category is physical product: apparel, accessories, bags, home goods, beauty, small electronics. Especially strong for catalog-breadth brands with multiple SKUs / prints / colorways.
- The buyer wants a **variant set** (8–12 ads), not a single hero. In-game ad networks reward more creatives + more variety over cherry-picking one winner. Variety is the strategy.

Do **not** use this pattern for:

- Meta / TikTok / YouTube Shorts placements — those reward front-loaded hooks in the first 2s. Use the standard Meta hook playbook there.
- B2B / SaaS / lead-gen (in-game is consumer-impulse inventory).
- Single-SKU launches where there's no variety to express. (Pick the Single-Product Feature angle below and ship 3–4 variants of *just that one*.)

### Why in-game inventory is different (do not skip)

| Channel | Hook window | Offer placement | Audio default | Best length |
|---|---|---|---|---|
| Meta / TikTok | 0–2s | first 3s | sound-on assumed | 6–15s |
| **In-game (interstitial)** | **5–15s forced view** | **last 5–7s only** | **sound-OFF dominant** | **30–45s** |

Translate this into four non-negotiables (the large majority of ads on in-game inventory run longer than 30s):

1. **Build for 30–45s.** Anything under 20s wastes the captive window.
2. **Earn attention before pushing the offer.** Never put price, discount, or a quantity-discount offer in the first 10 seconds. The viewer can't leave — you have time. Use it.
3. **Caption every spoken word.** Sound is off in gameplay 60–80% of the time.
4. **Design the final 5–7s as a dedicated CTA card** (muted captions, branded badge, price chip, URL pill). This is where the offer, USP, and brand wordmark land.

### What ships outside the video (tell the user)

The **interactive end card** rendered *after* the video drives roughly half of the channel's CTR. It's built in the network's ad manager dashboard, not in the video file. Every time you deliver a video set, remind the user to also configure end cards in the dashboard. Without them they're leaving ~50% of CTR on the table.

### How to read performance (tell the user)

In-game dashboards tend to report ROAS **conservatively**. Judge the set on new-customer ROAS via a post-purchase survey + MMM tool (e.g. an attribution / incrementality platform), not the network UI alone.

## 2. The five concept angles

Pick **one angle per ad**, ship a set that covers 3–4 different angles. Full menu in `references/concept-angles.md`. Snapshot:

1. **Print Parade / Variety Showcase** — one persona, one setting, ~6 product variants rotated through. Identity-recognition hook ("Tell me you're a ___ person without telling me…"). Best for catalog-breadth brands. ~35s.
2. **Single-Product Feature Ad** — 30s, 5-beat script: hook → material/texture macro → capacity/utility → interior detail → CTA. Pushes one SKU hard. ~30s.
3. **Gift Reveal / Emotional Unboxing** — 33s, 6 beats: wrapped gift → unwrap → emotional reveal → embroidery/material macro → variety menu → CTA. Best for Q4, Mother's Day, Valentine's, birthday windows. Narrator is the *giver*; on-camera reaction is the *recipient*.
4. **POV Diary / One Day In The Life** — 30s, 6 beats: morning → leaving home → midday errand (farmer's market, café, school run) → core use moment (beach, picnic, gym) → evening (sunset, dinner, home) → CTA. First-person narrator. Best for lifestyle-aspirational positioning.
5. **Identity Hook / Founder UGC / Pattern Montage** — three additional angles available; see `references/concept-angles.md`.

Across a launch, **mix angles**. Don't ship 8 Print Parades — ship 3 Print Parades + 3 Feature + 2 Gift Reveals (or similar mix). Variety in *angle* is more valuable than variety in *prop*.

## 3. Hook & opening (the structural move)

**The in-game hook is not the first 2 seconds — it's the first 10.** The viewer is locked in; you do not need to interrupt them. You need to *intrigue* them.

Acceptable opening structural moves:

- **Identity recognition** — "Tell me you're a [city cyclist / plant parent / weekend hiker] without telling me you're a [city cyclist / plant parent / weekend hiker]." Persona looks at camera, smiles, holds the product. Generic example: *"Tell me you commute by bike… without telling me."* — opens Print Parade.
- **Emotional setup** — wrapped present, hands only, soft piano. No copy. Caption: "They have no idea what's inside." Opens Gift Reveal.
- **POV cold-open** — first-person, no narrator yet, just sound of the morning. Caption fades in by second 3: "Monday. 6am. Trail day." Opens POV Diary.
- **Product-as-character close-up** — slow push-in on material/texture *before* you reveal what it is. Caption asks a question ("What is this material?"). Opens Single-Product Feature.

**Swap the subject, keep the move.** The hook archetype is the locked element. Persona, product, line, environment — all swappable. If the user brings a different audience, the identity-recognition becomes "Tell me you're a [their audience]…". If it's a tech accessory not a bag, the texture push-in becomes a close-up on the device, not on fabric.

## 4. Narrative arc per angle (beat list)

Each angle has its own beat shape. Pick one, then size every scene to land 30–45s total.

**Print Parade (~35s, 6–7 beats, ~5s each)**
1. Hook line + persona reveal with product #1 *(5s)*
2–6. Quick wardrobe-change-style cuts: same persona, same setting, products #2–#6 rotated *(5s each)*
7. CTA card *(5–7s, muted captions)*

**Single-Product Feature (~30s, 5 beats, ~6s each)**
1. Hook (product question or texture push-in) *(6s)*
2. Material/texture macro + tactile VO *(6s)*
3. Capacity / utility shot (in use) *(6s)*
4. Interior or unexpected-detail beat *(6s)*
5. CTA card *(5–7s)*

**Gift Reveal (~33s, 6 beats)**
1. Wrapped gift, narrator setup *(5s)* — narrator is the giver
2. Unwrap action, hands only *(5s)*
3. Recipient's emotional reaction *(6s)* — this is the money shot
4. Embroidery / material detail macro *(5s)*
5. Variety menu (2–3 alternate prints in quick succession) *(6s)*
6. CTA card *(5–7s)*

**POV Diary (~30s, 6 beats, ~5s each)**
1. Morning (window, coffee, bag on chair)
2. Leaving home (door, keys, bag on shoulder)
3. Midday errand (market, café, child pickup)
4. Core use moment (beach, picnic, gym)
5. Evening (sunset, dinner, drive home)
6. CTA card

**Where the offer lands: the CTA beat only.** Price, discount, free-shipping threshold, returns policy — all in the final CTA beat. Never earlier.

## 5. Visual style spec

- **Aspect & duration:** 9:16, 30–45s. Default to 31–35s unless the angle calls for longer.
- **Cinematic vs UGC:** match to angle. Print Parade and POV Diary lean *cinematic-lifestyle* (locked-off or slow push-in, golden hour, shallow DoF). Single-Product Feature leans *UGC-pulse* (handheld, brighter, faster cuts). Gift Reveal is *quiet cinematic* (warm interior, soft window light, no handheld).
- **Color palette:** lock one brand accent color and reuse it across the set as the CTA chip / wordmark accent. Pick the brand's accent and apply it to every CTA card in the set. If the brand doesn't have a defined accent, pull one from the product or the website hero and document it.
- **Shot length distribution:** target 4–6s per scene for narrative angles, 5s flat for Print Parade rotations. Avoid <3s cuts (in-game viewers don't need MTV pacing — they're captive).
- **On-screen text policy:** captions render every spoken word automatically. Only add `text_overlays` for non-duplicative accents (price chip, brand wordmark, CTA pill, free-shipping badge), and only on the CTA scene with `mute_captions: true`. Putting overlay text on top of live captions is a hard "don't" — they collide and both become unreadable.
- **Hook title:** use `hook_overlay` (not `text_overlays`) for the opening title card. This keeps the hook visually distinct from CTA-card text overlays.

## 6. Voice & persona

**Persona policy** (use `setup_persona`; compose the persona prompt with `ads-persona-prompt-skill` if available):

- Anchor every persona to a **beauty-floor description** (skin clarity, hair, eye contact, posture) — the avatar model otherwise drifts to mid-attractive default.
- Apply the **modesty triplet** for apparel/lifestyle: covered shoulders or sleeves, modest neckline, mid-rise or higher waistline. Don't let the model invent swimwear unless the product is swimwear.
- Use a **generic environment** (beach, kitchen, market) — never a recognizable real location.
- Give the persona **one signature detail** (a freckle pattern, a specific earring, a hair clip) — anchors visual continuity across scenes.
- **Rotate persona ethnicity and age across the ad set** for representation. Each variant ad gets a *different* persona — vary skin tone, age band, and hair so no two ads in a launch share the same on-camera person.
- For narrator-only angles (Gift Reveal narrator, Print Parade VO, POV Diary VO), use `voice_only=true` and a separate `setup_persona` call for the narrator's voice asset.

**Voice & tone per angle:**

- Print Parade: warm middle-aged female, conversational, smile-in-voice.
- Single-Product Feature: late-20s/early-30s female, peer-to-peer enthusiasm, slight UGC rasp.
- Gift Reveal: younger warm female narrator over the recipient's reaction; whispered/intimate.
- POV Diary: first-person, calm, present-tense, almost journaling.

**Speech-pacing band: 1.5–3.0 words/second, target 2.5.** This is the single hardest rule. Below 1.5 w/s the avatar model stretches words and the VO sounds robotic and underwater. If a cinematic scene is too sparse to hit 1.5 w/s, either **densify the line** (add a half-sentence) or **shorten the scene duration**. The director rejects scenes outside this band — pre-check every dialogue line by counting words ÷ scene seconds before dispatch.

**Don't echo VO in `text_overlays`.** Captions already render every spoken word. Overlays are for things the VO does *not* say (price, brand mark, CTA verb).

## 7. CTA mechanic (the close)

The CTA is its own scene at the end of every ad — 5–7s, with **`mute_captions: true`** so the only text on screen is what you put in `text_overlays`.

Required elements in the CTA scene:

1. **Product hero shot** (clean front-on or 3/4, neutral background, brand color accent).
2. **Brand wordmark** as a top or top-left overlay.
3. **Price chip** showing both anchor and sale price (e.g. `$49.00 → $24.50`).
4. **Offer pill** with the active promo verbatim from the brand (e.g. `Buy 2 Get 15% Off`, `Free shipping over $50`, `Free returns within 30 days`).
5. **URL pill** with the bare domain (e.g. `example-shop.com`).
6. **Tagline** if the brand has one short enough (e.g. *"Built for everyday carry."*).

Spoken CTA, if any, is a single short line — *"Get yours at [domain]"* — and lands in the **first 1–2s** of the CTA scene, leaving the remaining 4–5s as a silent legibility hold.

Also tell the user, every delivery: **configure the interactive end card in the ad network dashboard.** It carries ~50% of channel CTR and is not part of the video file.

## 8. Caption preset & font rotation (anti-defaulting rule)

LLMs default. Across an 8–12 variant set, every ad will end up with the same `outlined-text` / `promo-punch` preset and Poppins/Montserrat font unless you force variety. **Each ad in the set MUST use a different caption preset + font from the prior ads.** See `references/caption-presets.md` for a sample four-preset rotation (mint+Corben, zoom-punch+Anton, editorial-clean+Alice, soft-pill+DM-Sans) and how to extend it.

Hook overlay styles also rotate: pill / outlined / minimal / minimal across the set.

## 9. Brand info handoff (do-not-fabricate gate)

Every brand fact that appears in copy, overlays, or VO **must** come from one of:

- A `web_fetch` of the brand's product detail page (PDP) — collection-page fetches alone do not pass the gate.
- The user's chat (a price, a promo, a tagline they typed).
- An uploaded asset inspected via `get_asset`.

Do not invent prices, discounts, shipping thresholds, return windows, or taglines. The director enforces this gate and will reject scenes whose `brand_info` or `product_info` fields aren't sourced. If a PDP fetch fails, ask the user — don't guess.

## 10. Hard rules / do-not-regress

Treat each line below as a hard rule.

1. **Build for 30–45s.** Default 31–35s. Anything <20s wastes the captive window.
2. **Never front-load the offer.** Price, discount, shipping, returns, tagline — CTA scene only.
3. **Caption every spoken word** (the assembler does this automatically; do not disable it).
4. **`mute_captions: true` on the CTA scene only.** All other scenes keep live captions.
5. **`text_overlays` are for the CTA scene only** and must not echo VO. Use them for price chip / brand mark / offer pill / URL / tagline.
6. **`hook_overlay` is for the opening title only.** Never reuse it for the CTA card.
7. **Speech pacing 1.5–3.0 w/s, target 2.5.** Pre-check every line. Densify or shorten — never ship under 1.5.
8. **Brand facts must be sourced** (PDP fetch or user chat). No fabrication.
9. **Each ad in a set uses a different caption preset + font** from the prior ads. Rotate hook-overlay style too.
10. **Rotate persona ethnicity / age across the set.** Same persona twice in one launch is a regression.
11. **Mix angles across a launch** (3 of one angle max). 8–12 variants total, never 1–2.
12. **PRODUCT REFERENCE vs BACKGROUND PROP labels** must be set correctly on every director dispatch: the hero / held product is `PRODUCT REFERENCE`, anything incidentally in frame (other items on a shelf, a bag on a chair in scene 1) is `BACKGROUND PROP`.
13. **Remind the user about the interactive end card** every delivery. It's not in the video file but it drives ~50% of CTR.
14. **Judge ROAS on a new-customer ROAS / incrementality tool**, not the network dashboard.
15. **Music in parallel with persona setup.** Track must match angle (warm Americana acoustic for Print Parade; upbeat tropical pop for UGC Feature; emotional piano for Gift Reveal; warm indie-folk for POV Diary).
