# Image Handoff Template (Layout-Mirror)

Fill in the bracketed fields. Send as the director handoff body. Order matters — product reference first, then layout prose, then text overlays, then constraints.

```
PRODUCT REFERENCE: [input:image-N — clean front-of-pack of the user's product]
Preserve exactly:
- Wordmark: "[exact spelling, casing]"
- Pack shape: [flat-bottom standup pouch / cylindrical canister / glass bottle / etc.]
- On-pack headline: "[verbatim]"
- Decorative elements: [stripes / waves / illustrations / icon row — describe each]
- Feature bullets on pack (paraphrase each, do not invent): [bullet 1], [bullet 2], …
- Weight / volume callout: "[e.g. 1000g]"
- URL / brand line on pack: "[verbatim if present]"
- Cap / closure: [zip-top / screw cap / push-pull / none]

LAYOUT (reference image [input:image-M] is a TEMPLATE ONLY — do not reproduce its product, colors, or wordmark):
- Aspect ratio: [1:1 / 4:5 / 9:16]
- Top third: [headline band — centered / left-aligned, color, weight]
- Mid-left: [secondary visual — e.g. hand pouring powder from scoop into glass, single delicate stream, soft cloud at impact]
- Mid-right: [hero product cluster — the user's pack, standing, slightly angled, soft contact shadow]
- Bottom band: [3 pill-shaped chips on cream / neutral bar]
- Background: [bright kitchen counter / studio sweep / lifestyle environment, soft natural light from upper left]
- Negative space: [where the rating row would be — leave clean if omitting]

TEXT OVERLAYS (bake into image, render exactly, including all non-ASCII characters):
- Headline (top, centered, bold sans-serif, dark on light): "[≤8 words]"
- Chip 1 (bottom-left, pill, dark on cream): "[≤3 words, e.g. "20g Protéine"]"
- Chip 2 (bottom-center): "[≤3 words]"
- Chip 3 (bottom-right): "[≤3 words]"

CRITICAL CONSTRAINTS:
- Do NOT include the reference brand's product, brand colors, or wordmark anywhere in the image.
- Packaging silhouette: keep it a [pouch / canister / bottle] — not any other shape.
- Anatomy: if a hand is visible, fingers and wrist only, anatomically correct, exactly five fingers, no extra digits, no warped knuckles.
- Pour physics: single delicate stream of [powder / liquid], soft cloud / ripple where it meets the receiving vessel, no spillage on the counter.
- Typography fidelity: every on-screen word renders exactly as written, including umlauts and accents; no garbled or invented letterforms.
- Rating row: [include / OMIT — default OMIT].
```

## Notes

- If the reference has no rating row, no chip rail, or no secondary action shot, just drop those lines from LAYOUT — don't invent slots that weren't in the reference.
- The PRODUCT REFERENCE block grows with how detailed the user's pack is. Skimping here is the #1 cause of packaging drift.
- TEXT OVERLAYS should be the only place verbatim on-screen copy appears. Don't sprinkle the same headline through the prose layout block — it confuses the renderer.
