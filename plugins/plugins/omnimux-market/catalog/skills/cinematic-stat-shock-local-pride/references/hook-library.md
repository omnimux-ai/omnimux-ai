# Knowledge-Gap Hook Library

These are plug-and-play variations on the two-line knowledge-gap hook structure.
All use the same Anton gold centered format. Swap subject matter; keep the tension arc.

## Formula
```
Line 1: [What the crowd universally believes / acknowledges]
Line 2: [The gap — what they're missing / wrong about]
```

## Sports / Geography
```
EVERYONE NAMES THE BIG CITY.
THE VENUE IS SOMEWHERE ELSE.
```
```
MILLIONS WATCHED THE FINAL.
ZERO KNEW WHERE IT WAS PLAYED.
```
```
THEY ALL CLAIMED THE CITY.
THE STADIUM TELLS A DIFFERENT STORY.
```

## Local Pride / Reclamation
```
EVERYONE VISITS THE COAST.
FEW KNOW THE NAME OF THE TOWN.
```
```
THEY WEAR THE SKYLINE.
WE WEAR THE ZIP CODE.
```
```
THE CREDIT GOES ELSEWHERE.
THE ROOTS STAY HERE.
```

## Cultural Correction
```
EVERYONE KNOWS THE SONG.
FEW KNOW WHERE IT STARTED.
```
```
THE WORLD LOVES THE FOOD.
THE NEIGHBORHOOD MADE IT.
```

## Event / Moment
```
EVERYONE WATCHED THE MOMENT.
NOT EVERYONE KNOWS THE PLACE.
```
```
THE EVENT WAS GLOBAL.
THE LOCATION WAS LOCAL.
```

---

## Hard rules for hook copy
- Maximum 8 words per line (shorter = stronger)
- Line 2 must be a revelation, not just a restatement of Line 1
- Both lines should feel like they could be on the product itself
- Never use question format — statements only, no "DO YOU KNOW WHERE?"
- Avoid negatives in Line 1 — start from what's true/believed, then subvert in Line 2
