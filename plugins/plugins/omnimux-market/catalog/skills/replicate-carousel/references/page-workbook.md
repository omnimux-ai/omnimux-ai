# 逐页工作表

用于参考拆解、商品迁移和生成检查。同一页号贯穿全流程；交付只展示用户需要的字段。

## 参考索引

记录来源链接或附件、实际查看方式、已查看页、缺失页、总页数是否确认，以及全套比例、色彩、字体、光线和人物连续性。

参考文件清单逐页包含：页号、来源页面、实际媒体来源、绝对本地路径、像素尺寸、下载验证状态、主代理查看状态。生成记录逐页包含：商品图路径、实际传入的参考图路径、辅助图路径（如有）、生成状态与输出路径。参考文件清单和实际生成输入必须能对应，不能用提示词中的描述代替图片输入。

## 每页字段

| 字段 | 内容 |
|---|---|
| 页号与来源 | 参考第几页；新增页注明延展设计 |
| 图片类型 | 画面实际看见什么，例如手持、穿搭、结构特写 |
| 内部版式 | 满幅、分屏、网格、主图加小窗；主体与留白位置 |
| 镜头与动作 | 景别、俯仰、朝向、握持或接触位置 |
| 文案逻辑 | 疑问、情境句、细节名等；长度、语气和位置 |
| 销售作用 | 这一页帮助买家理解什么 |
| 保留与替换 | 保留的视觉关系、替换内容和原因 |
| 商品依据 | 可见信息、已确认信息、未知项 |
| 新图内文案 | 确切文本；可以无字 |
| 保真要求 | 本页可见结构、图案、品牌文字等 |

## 提示词骨架

第 N 张独立轮播图，比例……。商品图 A 为产品外观依据；参考页 B 提供……构图和风格；生成页 C（如有）提供一致的光线或人物。

主体在……位置，做……动作；……景别与机位；背景……，道具……。版式……，光线……，留白……。图内文字逐字为“……”，放在……。商品必须保留……。不得添加本页未确认的……。

## 缺料处理示例

- 参考是打开水杯喝水，商品只有闭盖图：改成相同景别闭合手持，保留人物与文字区，说明未展示开盖的原因。
- 五页参考只能看封面：先分析封面，说明另外四页缺失；用户接受延展时自行设计后续四页并标注，不声称看过完整案例。
- 参考是效果对比，商品无测试资料：迁移为同版式的两个可见细节，不伪造前后效果。
