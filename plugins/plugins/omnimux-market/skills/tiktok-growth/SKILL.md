# TikTok 平台算法、视听节拍与矩阵带货增长技能

> **定位**：供社媒 Agent 在处理 TikTok 专属内容生产、分镜改写、爆款复刻与橱窗带货时调用的专业技能包。

---

## 1. TikTok 推荐算法与三大黄金核心指标

1. **3 秒完播率（3s Hold Rate）**：
   - TikTok 算法在视频分发初期，优先考核前 3 秒留存率（目标：≥ 65%）。
   - 前 3 秒内必须发生：**强视觉刺激（Visual Hook） + 痛点/反差口播（Verbal Hook） + 屏幕大字报（Text Hook）** 的三合一轰炸。
2. **总完播率（Completion Rate）**：
   - 15 秒短视频完播率需 ≥ 30%，中长短剧（60s+）完播率需 ≥ 15%。
   - 镜头切换节拍控制在 **1.5 秒 ~ 2.5 秒** 必切镜一次，防止观众视觉疲劳滑走。
3. **互动收藏率（Favorite / Share Rate）**：
   - 算法对“收藏（Favorite）”与“转发（Share）”的权重远高于单纯的点赞；
   - 视频尾段必须设计明确的社交货币或收藏动机（如“保存这份避坑清单”）。

## 2. 前 3 秒黄金 Hook（开头钩子）四大公式

在改写或制作 TikTok 短视频时，从以下 4 种爆款钩子中匹配一种：

| Hook 类型 | 表现形式与话术模板 | 适用带货品类 / 场景 |
| :--- | :--- | :--- |
| **① 认知颠覆 / 预期违背** | “90% 的人都不知道……”<br>“Stop doing this if you want……”<br>画面：出现违反常理的操作或反差画面。 | 美妆护肤、数码黑科技、生活痛点 |
| **② 极端对比 / 痛点暴击** | “Before vs After 左右分屏直接对比”<br>“如果你经常[痛点]，赶紧扔掉你手里的[旧方案]！” | 家居清洁、收纳、服装穿搭、个护 |
| **③ 社交证明 / 爆款跟风** | “TikTok made me buy this……”<br>“This went viral for a reason……”<br>画面：包裹开箱、真实使用瞬间。 | 爆品带货、好物推荐、潮玩礼品 |
| **④ 悬念提问 / 利益前置** | “Is this really worth the hype?”<br>“Here is the secret to [目标] without [代价]” | 测评种草、工具教程、性价比好物 |

## 3. TikTok 9:16 界面绝对安全区（Social Safe Zone）

由于 TikTok 移动端右侧常驻交互按钮（头像、点赞、评论、收藏、分享、旋转唱片），底部常驻作者名、Caption 文案与带货黄色购物车小黄车，画面构图必须遵守**严格避让法则**：

```text
┌──────────────────────────────────────────────┐
│ TOP: 留白 120px (避开顶部 Live/Following/ForYou)│
├──────────────────────────────────────────────┤
│                                              │
│                                              │
│          ★ 核心主体与关键字幕视窗 ★          │  RIGHT: 留白 140px
│             (CENTER SAFE WINDOW)             │  (避开头像/点赞/
│                                              │   评论/分享栏)
│                                              │
├──────────────────────────────────────────────┤
│ BOTTOM: 留白 280px (避开作者名、底部文案、   │
│         小黄车购物车按键及进度条)              │
└──────────────────────────────────────────────┘
```

- **分镜编译要求**：所有人物面部特写、商品核心卖点演示与动态居中字幕，必须锁定在 **安全视窗（Safe Window）** 内。

## 4. TikTok 图文轮播（Photo Carousel）高转化法则

图文轮播在 TikTok 具备极高的完播滑动率与收藏率：
1. **Slide 1（生死门封面）**：
   - 核心：大字号悬念大标题（极高对比度） + 强情绪/反差图片；
   - 目标：驱动用户产生第一次向左滑动（Swipe）动作。
2. **Slide 2 ~ 5（滑动牵引干货）**：
   - 每一页底端或右侧预留视觉引导箭头（Swipe Indicator）；
   - 内容高密度、步骤化推进，每页仅讲一个核心痛点或技巧。
3. **Slide 6 ~ 7（收藏终页 CTA）**：
   - 整理全篇精华总结图；
   - 结尾文案：“Save this post so you can find it later!”（引导点击收藏）。

---

## 5. 橱窗带货与发布合规（TikTok Shop Compliance）

1. **禁用生硬硬广腔**：文案以真实博主第一人称“实测、自用、避坑”口吻呈现；
2. **挂车引导合规**：
   - 尾段可口播：“Check the yellow cart below” 或 “Link in bio”；
   - 避免虚假绝对化词汇（如 No.1、100% 根治等）。
